🌐 ما هي JavaScript؟

تخيّل موقعاً إلكترونياً كاملاً: تصميم أنيق، ألوان جذابة، أزرار تفاعلية. هل تعرف أن هذا "الموقع الحي" لا يعمل بـ HTML و CSS فقط؟

HTML = الهيكل (عظام الموقع)
CSS = التنسيق (ملابس الموقع)
JavaScript = الحركة والتفاعل (عقل الموقع)

🎓
JavaScript هي اللغة الوحيدة التي تفهمها كل متصفحات الويب — Chrome, Firefox, Safari, Edge. بدونها، الإنترنت سيكون صفحات ثابتة مملة.

▶️ أول برنامج لك

في Python استخدمنا print()، في JavaScript نستخدم console.log():

JavaScript
console.log("Hello, World!");
📤 النتيجة
Hello, World!

تشريح الكود:

  • console = كائن جاهز للتحكم بالطرفية
  • .log() = دالة تطبع ما بين قوسيها
  • "..." = النص
  • ; = نهاية السطر

💬 التعليقات

تعليق سطر واحد:

JavaScript
// هذا تعليق
console.log("مرحبا"); // تعليق في نهاية السطر

تعليق متعدد الأسطر (ميزة لا توجد في Python):

JavaScript
/* هذا تعليق
   يمتد على عدة أسطر */
console.log("النتيجة");
💎
ميزة: JavaScript تسمح بتعليق متعدد الأسطر مباشرة. في Python تحتاج # لكل سطر.

🎯 أين يعمل الكود؟

JavaScript تعمل في مكانين:

1. المتصفح (Browser)

  • مدمج في كل متصفح
  • يتحكم بصفحات الويب
  • يستخدم DOM للتفاعل مع HTML

2. الخادم (Server)

  • عبر Node.js
  • لبناء APIs ومواقع كاملة
  • شركات كبرى: Netflix, PayPal
🎓
في هذا التطبيق، نشغّل JavaScript داخل بيئة المتصفح. كل الكود يعمل مباشرة.

🐛 أخطاؤك الأولى

خطأ 1: نسيان علامات الاقتباس

❌ خطأ
console.log(مرحبا)
💥 رسالة الخطأ
ReferenceError: مرحبا is not defined

الحل: أضف علامتي اقتباس.

خطأ 2: استخدام print()

❌ خطأ
print("مرحبا")
💥 رسالة الخطأ
ReferenceError: print is not defined

الحل: استخدم console.log().

خطأ 3: علامات اقتباس غير متطابقة

❌ خطأ
console.log("مرحبا')

الحل: تأكد أن البداية والنهاية من نفس النوع.

📝 اختبار سريع

1. ما الأمر لطباعة شيء في JavaScript؟

أ) print()
ب) console.log()
ج) echo
د) output()

2. كيف تُكتب التعليقات؟

أ) # تعليق
ب) // تعليق
ج) -- تعليق
د) ** تعليق

3. هل JavaScript هي Java؟

أ) نعم نفس اللغة
ب) لا، مختلفتان تماماً
ج) JavaScript نسخة مبسطة
د) حسب المتصفح

4. أين تعمل JavaScript؟

أ) المتصفح فقط
ب) الخادم فقط
ج) المتصفح والخادم
د) سطح المكتب فقط
