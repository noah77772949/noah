🎁 ثلاث طرق لإنشاء متغير

على عكس Python (طريقة واحدة)، JavaScript لديها ثلاث كلمات مفتاحية:

JavaScript
let name = "أحمد";
const age = 25;
var city = "دمشق";
الكلمة الاستخدام مثال
letقيمة قابلة للتغييرlet score = 0;
constقيمة ثابتة (لا تتغير)const PI = 3.14;
varالطريقة القديمة (تجنّبها)var x = 5;
⚠️
قاعدة عملية:
استخدم const دائماً كخيار أول.
فقط عندما تحتاج تغيير القيمة، استخدم let.
لا تستخدم var إلا لقراءة كود قديم.

🔒 let vs const

let — يسمح بالتغيير

JavaScript
let score = 0;
console.log(score);

score = 10;
console.log(score);

score = score + 5;
console.log(score);
📤 النتيجة
0
10
15

const — يمنع التغيير

❌ خطأ
const PI = 3.14;
PI = 3.15;
💥 رسالة الخطأ
TypeError: Assignment to constant variable.
💡
فلسفة const: اجعل قيمك ثابتة افتراضياً. هذا يجعل كودك أكثر أماناً — أي محاولة خاطئة لتغيير قيمة ستكتشف فوراً.

🔤 الأنواع الأساسية

JavaScript لديها 3 أنواع أساسية للبيانات (بالمقابل لأنواع Python):

JavaScript
let name = "أحمد";         // String (نص)
let age = 25;              // Number (رقم)
let price = 19.99;         // Number (لا يوجد int/float منفصل)
let isStudent = true;      // Boolean (منطقي)

الفرق المهم عن Python

Python JavaScript
int (عدد صحيح)Number (كل الأرقام)
float (عدد عشري)Number (نفس النوع)
strString
boolBoolean
Nonenull أو undefined
🎓
في JavaScript، 10 و 10.0 نفس النوع Number. هذا يبسّط الأمور لكن يخلق تحديات (مثل دقة الأرقام العشرية).

🎨 template literals — النصوص الذكية

في Python استخدمنا f-strings. في JavaScript، template literals (نفس الفكرة):

JavaScript — الطريقة القديمة
let name = "أحمد";
let age = 25;
console.log("اسمي " + name + " وعمري " + age);
JavaScript — الطريقة الحديثة
let name = "أحمد";
let age = 25;
console.log(`اسمي ${name} وعمري ${age}`);
📤 النتيجة
اسمي أحمد وعمري 25

مقارنة Python vs JavaScript

Python JavaScript
f"مرحباً {name}"`مرحباً ${name}`
⚠️
انتبه: في JavaScript، العلامة الخلفية `` ` `` (backtick) وليس ". موجودة في لوحة المفاتيح عند الضغط على زر مختلف.

🐛 أخطاء شائعة

خطأ 1: نسيان الكلمة المفتاحية

❌ خطأ
name = "أحمد";

السبب: JavaScript تعتقد أنك تحاول الوصول لمتغير غير موجود. الحل: أضف let أو const.

خطأ 2: استخدام const لمتغير متغير

❌ خطأ
const score = 0;
score = 10;

الحل: استخدم let بدلاً من const.

خطأ 3: استخدام اسم محجوز

❌ خطأ
let let = 5;

الحل: اختر اسماً آخر مثل myLet.

✏️ تمارين تطبيقية

تمرين 1 سهل

أنشئ متغيراً city = "دمشق" واطبعه.

💡 تلميح

استخدم let أو const.

✅ الحل 
const city = "دمشق";
console.log(city);
تمرين 2 سهل

أنشئ let score = 0;، ثم أضف 10، ثم أضف 5، واطبع القيمة النهائية.

💡 تلميح

استخدم score += 10; مرتين.

✅ الحل 
let score = 0;
score += 10;
score += 5;
console.log(score);
تمرين 3 متوسط

أنشئ 3 متغيرات (اسم، عمر، مدينة)، ثم اطبع جملة كاملة بـ template literal.

💡 تلميح

استخدم `` ` `` و ${}.

✅ الحل 
const name = "أحمد";
const age = 25;
const city = "دمشق";
console.log(`أنا ${name} من ${city} وعمري ${age} سنة`);
تمرين 4 متقدم

اكتب كوداً يعرض typeof 3 متغيرات مختلفة.

💡 تلميح

استخدم typeof.

✅ الحل 
const a = "نص";
const b = 42;
const c = true;
console.log(typeof a);
console.log(typeof b);
console.log(typeof c);

📝 اختبار سريع

1. ما الكلمة المفتاحية لمتغير لا يتغير؟

أ) let
ب) const
ج) var
د) fixed

2. ما الطريقة الأصح لكتابة اسم متغير؟

أ) first_name
ب) first name
ج) firstName
د) 1stName

3. كيف تكتب template literal؟

أ) f"مرحبا {name}"
ب) `مرحبا ${name}`
ج) "مرحبا %s"
د) "مرحبا + name"

4. ما نوع القيمة true؟

أ) string
ب) number
ج) boolean
د) object

5. ما الفرق بين let و const؟

أ) لا فرق
ب) let يسمح بالتغيير، const لا يسمح
ج) const للأرقام فقط
د) let للنصوص فقط
