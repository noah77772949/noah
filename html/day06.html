HTML5 Semantic Elements

Semantic elements have special meaning and describes it meaning to the browser. For instance,

and are not semantic elements because they do not give any meaning to a browser. However,
or is a semantic element because it clearly describe and defines its content. List of some semantic elements:

 <article>
 <aside>
 <details>
 <figcaption>
 <figure>
 <footer>
 <header>
 <main>
 <mark>
 <nav>

 <section>
 <summary>
 <time>
