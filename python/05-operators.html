🧮 العمليات الحسابية الأساسية

Python تدعم كل العمليات التي تعرفها من الرياضيات، وأكثر:

الرمز العملية مثال النتيجة
+جمع10 + 515
-طرح10 - 55
*ضرب10 * 550
/قسمة10 / 52.0
//قسمة صحيحة10 // 33
%الباقي10 % 31
**القوة2 ** 38
Python
print(10 + 5)
print(10 - 5)
print(10 * 5)
print(10 / 5)
print(10 // 3)
print(10 % 3)
print(2 ** 3)
📤 النتيجة
15
5
50
2.0
3
1
8

🔍 السر: الفرق بين / و //

هذا أهم فرق يجب أن تفهمه:

Python
print(10 / 3)   # قسمة عادية
print(10 // 3)  # قسمة صحيحة
📤 النتيجة
3.3333333333333335
3

القسمة العادية /: تعطي النتيجة الحقيقية (عدد عشري).

القسمة الصحيحة //: تُهمل الكسر تماماً، وتُعيد العدد الصحيح فقط.

💡
ملاحظة: 10 / 5 نتيجتها 2.0 وليس 2. لأن / تُعيد دائماً float، حتى لو كانت النتيجة صحيحة.

🎁 سرّ العلامة % — الباقي

علامة % تُعيد باقي القسمة. تبدو بسيطة، لكنها من أقوى أدوات البرمجة:

Python
print(10 % 3)   # 10 ÷ 3 = 3 والباقي 1
print(10 % 5)   # 10 ÷ 5 = 2 والباقي 0
print(7 % 2)    # 7 ÷ 2 = 3 والباقي 1
print(8 % 2)    # 8 ÷ 2 = 4 والباقي 0
📤 النتيجة
1
0
1
0

🧠 كيف تكشف الزوجي والفردي؟

Python
number = 7
print(number % 2)

القاعدة:

  • إذا كان x % 2 == 0 → العدد زوجي
  • إذا كان x % 2 == 1 → العدد فردي
🎓
استخدامات أخرى لـ %:
• تحديد مضاعفات (مثل كل 5 دقائق)
• دورة الأيام (اليوم 100 → أي يوم في الأسبوع؟)
• توزيع العناصر على مجموعات

⚡ القوة **

لرفع عدد لقوة، استخدم **:

Python
print(2 ** 3)    # 2 × 2 × 2 = 8
print(5 ** 2)    # 5 × 5 = 25
print(10 ** 6)   # مليون
print(2 ** 0)    # أي عدد أس صفر = 1
print(2 ** -1)   # = 0.5
📤 النتيجة
8
25
1000000
1
0.5
💎
في لغات أخرى، تُكتب Math.pow(2, 3). في Python، فقط 2 ** 3 — أنظف وأسرع.

📐 أولوية العمليات

عند خلط عدة عمليات في سطر واحد، Python تتبع ترتيباً صارماً (نفس الرياضيات):

الأولوية العملية
1 (الأعلى)() الأقواس
2** القوة
3* / // %
4 (الأدنى)+ -
Python
print(2 + 3 * 4)      # 3 * 4 = 12، ثم 2 + 12 = 14
print((2 + 3) * 4)    # 2 + 3 = 5، ثم 5 * 4 = 20
print(2 ** 3 + 1)     # 2 ** 3 = 8، ثم 8 + 1 = 9
print(10 - 2 * 3)     # 2 * 3 = 6، ثم 10 - 6 = 4
📤 النتيجة
14
20
9
4
⚠️
نصيحة: عند الشك، استخدم الأقواس. الكود الواضح أفضل من الكود الذكي. حتى لو كانت الأولوية واضحة، الأقواس تُساعد القارئ.

🔗 العمليات المنطقية

Python تدعم ثلاث عمليات منطقية على القيم المنطقية:

1. and — "و"

يُعيد True فقط إذا كان الطرفان True.

Python
print(True and True)
print(True and False)
print(False and False)
📤 النتيجة
True
False
False

2. or — "أو"

يُعيد True إذا كان أحد الطرفين True على الأقل.

Python
print(True or False)
print(False or False)
print(True or True)
📤 النتيجة
True
False
True

3. not — "ليس"

يقلب القيمة: True → False، والعكس.

Python
print(not True)
print(not False)
📤 النتيجة
False
True

🧠 تطبيق عملي

Python
age = 25
has_license = True

can_drive = age >= 18 and has_license
print(f"هل يمكنه القيادة؟ {can_drive}")
📤 النتيجة
هل يمكنه القيادة؟ True

⚡ اختصارات التعيين

عندما تريد تحديث متغير بناءً على قيمته الحالية، هناك اختصارات مريحة:

الاختصار يعني
x += 5x = x + 5
x -= 3x = x - 3
x *= 2x = x * 2
x /= 4x = x / 4
x //= 2x = x // 2
x %= 3x = x % 3
x **= 2x = x ** 2
Python
score = 100
score += 50   # score = 150
score -= 30   # score = 120
score *= 2    # score = 240
print(score)
📤 النتيجة
240
⚡
لماذا هذه الاختصارات مفيدة؟
• أقصر: سطر أقل
• أوضح: تعرف فوراً أنها "تحديث" وليس إنشاء
• أسرع قليلاً في التنفيذ

🐛 أخطاء شائعة

خطأ 1: خلط / و //

❌ خطأ منطقي
students = 25
groups = 4
per_group = students / groups
print(per_group)
📤 النتيجة
6.25

لا يمكن أن يكون في المجموعة 6.25 طالب! استخدم // أو round().

خطأ 2: القسمة على صفر

❌ خطأ
print(10 / 0)
💥 رسالة الخطأ
ZeroDivisionError: division by zero

خطأ 3: نسيان الأولوية

❌ خطأ منطقي
average = 10 + 20 + 30 / 3
print(average)
📤 النتيجة الخاطئة
40.0

المتوقع: 20 (مجموع 60 ÷ 3). لكن الأولوية حسبت 30/3 أولاً. الحل: (10 + 20 + 30) / 3.

✏️ تمارين تطبيقية

تمرين 1 سهل

احسب: 15 + 7، 15 - 7، 15 * 7، واطبعهم.

💡 تلميح

ثلاث عمليات print منفصلة.

✅ الحل 
print(15 + 7)
print(15 - 7)
print(15 * 7)
تمرين 2 سهل

اطبع باقي قسمة 17 على 5، ثم باقي قسمة 100 على 7.

💡 تلميح

استخدم %.

✅ الحل 
print(17 % 5)
print(100 % 7)
تمرين 3 متوسط

احسب مساحة دائرة نصف قطرها 5 (المساحة = π × r²). استخدم π = 3.14159.

💡 تلميح

لا تنسَ الأقواس: 3.14159 * (5 ** 2).

✅ الحل 
r = 5
area = 3.14159 * (r ** 2)
print(area)
تمرين 4 متوسط

أنشئ متغير balance = 1000. أضف 500، ثم اطرح 200، ثم اضرب في 2، واطبع النتيجة.

💡 تلميح

استخدم +=، -=، *=.

✅ الحل 
balance = 1000
balance += 500
balance -= 200
balance *= 2
print(balance)
تمرين 5 متقدم

اكتب كوداً يحدد إن كان الرقم 144 مربعاً كاملاً (مثلاً: 144 = 12²). اطبع النتيجة.

💡 تلميح

المربع الكامل = 12 ** 2 == 144.

✅ الحل 
n = 144
is_square = (12 ** 2) == n
print(is_square)
