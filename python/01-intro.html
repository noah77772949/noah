💡 ما هي البرمجة؟

تخيّل أنك تريد أن تطلب من صديق أجنبي أن يُعدّ لك كوب شاي، لكنه لا يفهم لغتك العربية إطلاقاً. كيف ستشرح له؟

ستستخدم لغة مشتركة يفهمها هو، مثل الإنجليزية. وتُعطيه خطوات دقيقة ومتسلسلة: "خذ الكوب، املأه ماءً، ضعه على النار، أضف الشاي..." إلخ.

🎓
البرمجة هي بالضبط هذا: أنت تعطي الكمبيوتر تعليمات دقيقة ومتسلسلة بلغة يفهمها، ليقوم بمهمة ما.

لكن الكمبيوتر غبي جداً في الحقيقة — لا يفهم النية، لا يفترض، ولا يستنتج. إن قلت له "خذ الكوب" سيسأل: أي كوب؟ في أي غرفة؟ بأي يد؟

لذلك لغة البرمجة يجب أن تكون واضحة، دقيقة، وخالية من الغموض.

⚙️ كيف يعمل Python؟

هناك نوعان رئيسيان من اللغات البرمجية:

النوع طريقة العمل أمثلة
مُترجَمة (Compiled) يُترجم الكود كاملاً إلى لغة الآلة ثم يُنفّذ C, C++, Rust, Go
مُفسّرة (Interpreted) يُترجم ويُنفّذ سطراً بسطر أثناء التشغيل Python, JavaScript, Ruby

Python لغة مُفسّرة. هذا يعني أن هناك برنامجاً اسمه المفسر (Interpreter) يقرأ كودك سطراً بسطر وينفّذه فوراً.

🔄 رحلة الكود في Python
📝 أنت تكتب: print("مرحباً")

🧠 يفهم: "أريد طباعة شيء"

✅ الشاشة تُظهر: مرحباً
📌
ملاحظة: عندما تحفظ ملف Python، يجب أن ينتهي اسمه بـ .py. مثلاً: hello.py أو my_program.py.

🚀 أول برنامج لك

كلمة "Hello, World!" (مرحباً بالعالم) هي التقليد المتعارف عليه في كل لغة برمجة جديدة. لنبدأ بها:

Python hello.py 
print("Hello, World!")
📤 النتيجة
Hello, World!

انتهى! هذا برنامجك الأول. 😄

لكن دعنا نفكّك ما حدث:

  • print هي دالة (Function) — أي أمر جاهز يقوم بمهمة محددة.
  • الأقواس () تُخبر Python أن "الآن استدعِ هذه الدالة".
  • العلامات " " تُخبر Python أن ما بينهما هو نص وليس أمراً.
  • النص المُعطى للدالة يسمى وسيطاً (Argument).
⚠️
خطأ شائع: نسيان علامات الاقتباس. لو كتبت print(Hello) سيحاول Python البحث عن متغير اسمه Hello ولن يجده، وسيظهر خطأ.

🔍 دالة print() بالتفصيل

يبدو أن print بسيطة، لكنها أعمق مما تظن. لنكتشف كل قدراتها:

1. طباعة نص

Python
print("أهلاً بك في عالم البرمجة")

2. طباعة رقم

Python
print(42)
print(3.14)

3. طباعة عدة أشياء معاً

Python
print("عمري", 25, "سنة")
📤 النتيجة
عمري 25 سنة

لاحظ: Python أضافت مسافة تلقائياً بين كل وسيطين.

4. تغيير الفاصل

Python
print("أ", "ب", "ج", sep="-")
📤 النتيجة
أ-ب-ج

5. التحكم بنهاية السطر

Python
print("مرحباً", end=" ")
print("بك")
📤 النتيجة
مرحباً بك

عادةً print تنزل سطراً جديداً بعد الطباعة، لكن end=" " جعلتها تُكمل في نفس السطر.

💡
معلومة: الرمز \n يعني "سطر جديد". إذا كتبت print("أ\nب") سيظهر:
أ
ب

💬 التعليقات (Comments)

التعليقات هي نصوص في الكود لا ينفّذها Python. وجودها لسببين:

  1. توضيح الكود لك أو لمن يقرأه لاحقاً
  2. تعطيل سطر مؤقتاً دون حذفه

تبدأ التعليقات في Python بالرمز #:

Python
# هذا تعليق — Python ستتجاهله
print("هذا يُنفّذ")  # تعليق في نهاية السطر

# print("هذا معطّل مؤقتاً")
📤 النتيجة
هذا يُنفّذ
⚠️
Python لا تملك تعليقات متعددة الأسطر مثل بعض اللغات. لكن يمكنك كتابة:
# سطر 1
# سطر 2
# سطر 3

🐛 أخطاؤك الأولى

الأخطاء ليست نهاية العالم — هي معلّمك الأول. إليك أشهر 3 أخطاء للمبتدئين:

خطأ 1: نسيان علامات الاقتباس

❌ خطأ
print(Hello)
💥 رسالة الخطأ
NameError: name 'Hello' is not defined

الترجمة: "اسم Hello غير معرّف". الحل: أضف علامات اقتباس.

خطأ 2: نسيان الأقواس

❌ خطأ
print "مرحباً"
💥 رسالة الخطأ
SyntaxError: Missing parentheses in call to 'print'

الترجمة: "أقواس مفقودة في استدعاء print". الحل: أضف الأقواس.

خطأ 3: علامات اقتباس غير متطابقة

❌ خطأ
print("مرحباً)
💥 رسالة الخطأ
SyntaxError: unterminated string literal

الترجمة: "نص لم يُغلق". الحل: تأكد أن علامتَي الاقتباس متطابقتان.

🧠
قاعدة ذهبية: عندما يظهر خطأ، اقرأ آخر سطر من الرسالة أولاً — هو عادةً يشرح المشكلة بوضوح.
