📦 ما هي القائمة؟

تخيّل صندوقاً فيه عدة عناصر مرتبة.

Python
fruits = ["تفاح", "موز", "برتقال", "عنب"]
numbers = [1, 2, 3, 4, 5]
mixed = [10, "نص", True, 3.14]
empty = []
🎓
القائمة تُكتب بين [] وتُفصل العناصر بـ ,. يمكن أن تحتوي أنواعاً مختلفة.

📍 الفهرسة

كل عنصر له رقم (Index) يبدأ من 0:

Python
fruits = ["تفاح", "موز", "برتقال", "عنب"]
#            0        1        2        3
#           -4       -3       -2       -1

print(fruits[0])
print(fruits[2])
print(fruits[-1])
📤 النتيجة
تفاح
برتقال
عنب

الفهرس السالب يعني "من النهاية".

✏️ تعديل العناصر

Python
fruits = ["تفاح", "موز", "برتقال"]
fruits[1] = "بطيخ"
print(fruits)
📤 النتيجة
['تفاح', 'بطيخ', 'برتقال']

➕ إضافة وحذف

العمليةالدالة
إضافة في النهايةappend(x)
إضافة في موضعinsert(i, x)
حذف بالقيمةremove(x)
حذف بموضعpop(i)
حذف الكلclear()
Python
fruits = ["تفاح", "موز"]

fruits.append("برتقال")
print(fruits)

fruits.insert(1, "عنب")
print(fruits)

fruits.remove("موز")
print(fruits)

fruits.pop()
print(fruits)
📤 النتيجة
['تفاح', 'موز', 'برتقال']
['تفاح', 'عنب', 'موز', 'برتقال']
['تفاح', 'عنب', 'برتقال']
['تفاح', 'عنب']

✂️ التقطيع

Python
nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])
print(nums[:3])
print(nums[3:])
print(nums[-2:])
print(nums[::2])
📤 النتيجة
[20, 30, 40]
[10, 20, 30]
[40, 50, 60]
[50, 60]
[10, 30, 50]

القاعدة: [start:end:step] — النهاية غير مشمولة.

✏️ تمارين

تمرين 1سهل

أنشئ قائمة بأسماء 3 فواكه، واطبع كل واحدة في سطر.

💡 تلميح

استخدم for.

✅ الحل
fruits = ["تفاح", "موز", "عنب"]
for f in fruits:
    print(f)
تمرين 2سهل

أنشئ قائمة أرقام، واطبع أول عنصر وأخر عنصر.

💡 تلميح

استخدم [0] و [-1].

✅ الحل
nums = [10, 20, 30, 40]
print(nums[0])
print(nums[-1])
تمرين 3متوسط

أنشئ قائمة فارغة، أضف 5 أرقام، ثم اطبع المجموع والمتوسط.

💡 تلميح

استخدم append، sum، len.

✅ الحل
nums = []
nums.append(10)
nums.append(20)
nums.append(30)
nums.append(40)
nums.append(50)
print(sum(nums))
print(sum(nums) / len(nums))
تمرين 4متقدم

أنشئ قائمة، واطبع عناصرها بترتيب عكسي باستخدام التقطيع.

💡 تلميح

استخدم [::-1].

✅ الحل
nums = [1, 2, 3, 4, 5]
print(nums[::-1])

📝 اختبار

1. كيف نضيف عنصراً في نهاية القائمة؟

أ) add()
ب) append()
ج) push()
د) insert()

2. نتيجة [1, 2, 3, 4][-1]؟

أ) 1
ب) 4
ج) خطأ
د) [4]

3. ماذا يعطي [10, 20, 30][0:2]؟

أ) [10, 20]
ب) [10, 20, 30]
ج) [20, 30]
د) [30]

4. دالة حذف عنصر بالقيمة؟

أ) pop()
ب) remove()
ج) delete()
د) drop()

🎓 خلاصة

  • ✅ القائمة بـ []
  • ✅ الفهرسة من 0، والسالب من النهاية
  • ✅ الإضافة: append, insert
  • ✅ الحذف: remove, pop, clear
  • ✅ التقطيع: [start:end:step]
  • ✅ دوال: len, sum, min, max, sorted
