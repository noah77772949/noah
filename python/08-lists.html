القائمة (List) هي مجموعة مرتبة من العناصر. تُخزّن بين [ ] وتُفصل العناصر بفواصل. يمكن أن تحتوي أي نوع من البيانات.

📝 إنشاء القوائم

عدة طرق لإنشاء قائمة:

Python
# قائمة نصوص
fruits = ["تفاح", "موز", "برتقال", "عنب"]

# قائمة أرقام
numbers = [1, 2, 3, 4, 5]

# قائمة مختلطة
mixed = [10, "نص", True, 3.14]

# قائمة فارغة
empty = []

# قائمة بمتغير واحد
single = ["عنصر واحد"]

print(fruits)
print(numbers)
print(mixed)
📤 النتيجة
['تفاح', 'موز', 'برتقال', 'عنب']
[1, 2, 3, 4, 5]
[10, 'نص', True, 3.14]
💡
ملاحظة: القائمة يمكن أن تحتوي أنواعاً مختلفة (نصوص، أرقام، منطقيات) في نفس القائمة. هذا يختلف عن لغات مثل Java التي تحتاج نوعاً موحداً.

📍 الوصول للعناصر بالفهرسة

كل عنصر له رقم (Index) يبدأ من صفر:

Python
fruits = ["تفاح", "موز", "برتقال", "عنب"]
#            0        1        2        3

print(fruits[0])   # العنصر الأول
print(fruits[1])   # الثاني
print(fruits[2])   # الثالث
📤 النتيجة
تفاح
موز
برتقال
⚠️
الفهرس يبدأ من 0! العنصر الأول فهرسه 0، الثاني فهرسه 1، وهكذا. إذا طلبت فهرساً غير موجود، ستحصل على خطأ IndexError.

الفهرسة السالبة — من النهاية

Python تقدّم ميزة رائعة: فهارس سالبة للوصول من النهاية:

Python
fruits = ["تفاح", "موز", "برتقال", "عنب"]
#           -4       -3       -2       -1

print(fruits[-1])   # آخر عنصر
print(fruits[-2])   # قبل الأخير
print(fruits[-4])   # نفس fruits[0]
📤 النتيجة
عنب
برتقال
تفاح

عدّ العناصر

Python
fruits = ["تفاح", "موز", "برتقال", "عنب"]
print(len(fruits))
📤 النتيجة
4

➕ إضافة العناصر

Python تقدّم عدة دوال لإضافة عناصر للقائمة:

الدالةالوظيفةالموضع
append(x)تُضيف عنصراًفي النهاية
insert(i, x)تُدخل عنصراًفي الموضع i
extend(list)تُضيف قائمة كاملةفي النهاية

1. append — الإضافة في النهاية

Python
fruits = ["تفاح", "موز"]
print("قبل:", fruits)

fruits.append("برتقال")
print("بعد:", fruits)

fruits.append("عنب")
print("بعد آخر:", fruits)
📤 النتيجة
قبل: ['تفاح', 'موز']
بعد: ['تفاح', 'موز', 'برتقال']
بعد آخر: ['تفاح', 'موز', 'برتقال', 'عنب']

2. insert — الإدخال في موضع محدد

Python
fruits = ["تفاح", "موز", "عنب"]
print("قبل:", fruits)

fruits.insert(1, "برتقال")
print("بعد:", fruits)
📤 النتيجة
قبل: ['تفاح', 'موز', 'عنب']
بعد: ['تفاح', 'برتقال', 'موز', 'عنب']

لاحظ: "برتقال" دخل في الموضع 1، والباقي انزاح.

3. extend — إضافة قائمة كاملة

Python
fruits = ["تفاح", "موز"]
vegetables = ["جزر", "خيار"]

fruits.extend(vegetables)
print(fruits)
📤 النتيجة
['تفاح', 'موز', 'جزر', 'خيار']

🗑️ حذف العناصر

الدالةالوظيفة
remove(x)تحذف أول عنصر بقيمة x
pop(i)تحذف وتُرجع العنصر في الموضع i
del list[i]تحذف العنصر في الموضع i
clear()تُفرغ القائمة تماماً

1. remove — الحذف بالقيمة

Python
fruits = ["تفاح", "موز", "برتقال", "موز"]
print("قبل:", fruits)

fruits.remove("موز")
print("بعد:", fruits)
📤 النتيجة
قبل: ['تفاح', 'موز', 'برتقال', 'موز']
بعد: ['تفاح', 'برتقال', 'موز']

لاحظ: حُذف "موز" الأول فقط، والثاني بقي.

2. pop — الحذف بالموقع

Python
fruits = ["تفاح", "موز", "برتقال"]

last = fruits.pop()      # يحذف الأخير ويُرجعه
print("المحذوف:", last)
print("الباقي:", fruits)

second = fruits.pop(1)   # يحذف الموضع 1
print("المحذوف:", second)
print("الباقي:", fruits)
📤 النتيجة
المحذوف: برتقال
الباقي: ['تفاح', 'موز']
المحذوف: موز
الباقي: ['تفاح']

3. del — الحذف بموضع مباشر

Python
fruits = ["تفاح", "موز", "برتقال"]
del fruits[1]
print(fruits)
📤 النتيجة
['تفاح', 'برتقال']

4. clear — تفريغ القائمة

Python
fruits = ["تفاح", "موز", "برتقال"]
fruits.clear()
print(fruits)
📤 النتيجة
[]

✂️ التقطيع (Slicing)

استخراج جزء من القائمة باستخدام [start:end:step]:

Python
nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])    # من 1 إلى 3
print(nums[:3])     # من البداية إلى 2
print(nums[3:])     # من 3 للنهاية
print(nums[-2:])    # آخر عنصرين
print(nums[::2])    # كل عنصرين
print(nums[::-1])   # عكس القائمة
📤 النتيجة
[20, 30, 40]
[10, 20, 30]
[40, 50, 60]
[50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]
⚠️
القاعدة الذهبية: النهاية غير مشمولة.
nums[1:4] تُرجع العناصر 1, 2, 3 (وليس 4).

🔄 المرور على القوائم

1. الطريقة البسيطة

Python
fruits = ["تفاح", "موز", "عنب"]

for fruit in fruits:
    print(fruit)
📤 النتيجة
تفاح
موز
عنب

2. بالفهرس

Python
fruits = ["تفاح", "موز", "عنب"]

for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")
📤 النتيجة
0: تفاح
1: موز
2: عنب

3. بـ enumerate (الأفضل)

Python
fruits = ["تفاح", "موز", "عنب"]

for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
📤 النتيجة
0: تفاح
1: موز
2: عنب
💎
enumerate طريقة Python الحديثة للحصول على الفهرس والقيمة معاً في حلقة واحدة.

🐛 أخطاء شائعة

خطأ 1: الفهرس خارج النطاق

❌ خطأ
fruits = ["تفاح", "موز", "برتقال"]
print(fruits[5])
💥 رسالة الخطأ
IndexError: list index out of range

السبب: القائمة فيها 3 عناصر فقط، والفهرس 5 غير موجود. تذكّر: الفهارس من 0 إلى 2.

خطأ 2: نسيان علامات الاقتباس

❌ خطأ
fruits = [تفاح, موز, برتقال]
💥 رسالة الخطأ
NameError: name 'تفاح' is not defined

الحل: أضف علامات اقتباس حول كل نص.

خطأ 3: تعديل القائمة أثناء المرور عليها

❌ منطق خاطئ
nums = [1, 2, 3, 4, 5]

for n in nums:
    if n % 2 == 0:
        nums.remove(n)  # خطير!

هذا يُربك Python ونتائج غير متوقعة. الحل: أنشئ قائمة جديدة.

خطأ 4: الاعتقاد أن = تنسخ القائمة

❌ خطأ منطقي
a = [1, 2, 3]
b = a          # ليس نسخاً!
b.append(4)
print(a)       # سيتغير أيضاً!
📤 النتيجة
[1, 2, 3, 4]

الحل: استخدم b = a.copy() أو b = a[:] لنسخة مستقلة.

✅ الطريقة الصحيحة
a = [1, 2, 3]
b = a.copy()
b.append(4)

print("a:", a)
print("b:", b)
📤 النتيجة
a: [1, 2, 3]
b: [1, 2, 3, 4]

📝 اختبار سريع

1. كيف نضيف عنصراً في نهاية القائمة؟

أ) add()
ب) append()
ج) push()
د) insert()

2. ما نتيجة [1, 2, 3, 4][-1]؟

أ) 1
ب) 4
ج) خطأ
د) [4]

3. ماذا يعطي [10, 20, 30][0:2]؟

أ) [10, 20]
ب) [10, 20, 30]
ج) [20, 30]
د) [30]

4. ما دالة حذف عنصر بقيمته؟

أ) pop()
ب) remove()
ج) delete()
د) drop()

🎓 خلاصة الدرس

  • ✅ القائمة تُكتب بـ [] — قابلة للتعديل
  • ✅ الفهرسة تبدأ من 0، والسالب من النهاية
  • ✅ الإضافة: append، insert، extend
  • ✅ الحذف: remove، pop، del، clear
  • ✅ التقطيع: [start:end:step] — النهاية غير مشمولة
  • ✅ دوال: len، sum، min، max، sorted
  • ✅ enumerate للحصول على الفهرس والقيمة معاً
  • ✅ = لا ينسخ القائمة! استخدم .copy()
