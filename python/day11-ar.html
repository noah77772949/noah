    وظائف

    لقد رأينا حتى الآن العديد من وظائف بايثون المضمنة. في هذا القسم، سنركز على الوظائف المخصصة. ما هي الوظيفة؟ قبل أن نبدأ في إنشاء الوظائف، دعونا نتعرف على ما هي الوظيفة ولماذا نحتاج إليها؟

    تعريف الدالة

    الوظيفة عبارة عن كتلة قابلة لإعادة الاستخدام من التعليمات البرمجية أو بيانات البرمجة المصممة لأداء مهمة معينة. لتعريف دالة أو إعلانها، توفر بايثون التابعمواطنهالكلمة الرئيسية. ما يلي هو بناء الجملة لتعريف وظيفة. يتم تنفيذ كتلة الوظيفة من التعليمات البرمجية فقط في حالة استدعاء الوظيفة أو استدعائها.

    إعلان واستدعاء وظيفة

    عندما نصنع دالة، نسميها إعلان دالة. عندما نبدأ باستخدامه، نسميهالاتصالأواستدعاءوظيفة. يمكن الإعلان عن الوظائف مع أو بدون معلمات.

    # syntax
# Declaring a function
def function_name():
    codes
    codes
# Calling a function
function_name()

    عدد تعسفي من الحجج

    إذا لم نكن نعرف عدد الوسائط التي نمررها إلى وظيفتنا، فيمكننا إنشاء دالة يمكنها قبول عدد عشوائي من الوسائط عن طريق إضافة * قبل اسم المعلمة.

    # syntax
# Declaring a function
def function_name(*args):
    codes
    codes
# Calling function
function_name(param1, param2, param3,..)

    تفريغ القاموس

    يمكنك استدعاء دالة تحتوي على وسيطات باستخدام قاموس يحتوي على أسماء مفاتيح متطابقة. أنت تفعل ذلك باستخدام**.

    # Define a function that takes two arguments: 'name' and 'location'
def greet(name, location):
    # Print a greeting message using the provided arguments
    print("Hi there", name, "how is the weather in", location)

# Call the function using keyword arguments
greet(name="Alice", location="New York")  
# Output: Hi there Alice how is the weather in New York

# Create a dictionary with keys matching the function's parameter names
my_dict = {"name": "Alice", "location": "New York"}

# Call the function using dictionary unpacking
greet(**my_dict)  
# The ** operator unpacks the dictionary, passing its key-value pairs 
# as keyword arguments to the function.
# Output: Hi there Alice how is the weather in New York

    العدد التعسفي للوسائط المسماة

    يمكنك أيضًا تحديد دالة لقبول عدد عشوائي من الوسائط المسماة.

    def arbitrary_named_args(**args):
    print("I received an arbitrary number of arguments, totaling", len(args))
    print("They are provided as a dictionary in my function:", type(args))
    print("Let's print them:")
    for k, v in args.items():
        print(" * key:", k, "value:", v)

    بشكل عام، تجنب ذلك ما لم يكن ذلك مطلوبًا لأنه يجعل من الصعب فهم ما تقبله الوظيفة وما تفعله.
