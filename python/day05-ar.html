    القوائم

    هناك أربعة أنواع من بيانات المجموعة في بايثون:

    • القائمة: هي مجموعة مرتبة وقابلة للتغيير (قابلة للتعديل). يسمح بأعضاء مكررة.
    • Tuple: مجموعة مرتبة وغير قابلة للتغيير أو التعديل (غير قابلة للتغيير). يسمح بأعضاء مكررة.
    • المجموعة: هي مجموعة غير مرتبة وغير مفهرسة وغير قابلة للتعديل، ولكن يمكننا إضافة عناصر جديدة إلى المجموعة. لا يسمح بالأعضاء المكررين.
    • القاموس: عبارة عن مجموعة غير مرتبة وقابلة للتغيير (التعديل) والمفهرسة. لا يوجد أعضاء مكررة.

    القائمة عبارة عن مجموعة من أنواع البيانات المختلفة مرتبة وقابلة للتعديل (قابلة للتغيير). يمكن أن تكون القائمة فارغة أو قد تحتوي على عناصر مختلفة من نوع البيانات.

    # syntax

    الوصول إلى عناصر القائمة باستخدام الفهرسة الإيجابية

    يمكننا الوصول إلى كل عنصر في القائمة باستخدام الفهرس الخاص به. يبدأ فهرس القائمة من 0. الصورة أدناه توضح بوضوح أين يبدأ الفهرس

    fruits = ['banana', 'orange', 'mango', 'lemon']
first_fruit = fruits[0] # we are accessing the first item using its index
print(first_fruit)      # banana
second_fruit = fruits[1]
print(second_fruit)     # orange
last_fruit = fruits[3]
print(last_fruit) # lemon
# Last index
last_index = len(fruits) - 1
last_fruit = fruits[last_index]

    الوصول إلى عناصر القائمة باستخدام الفهرسة السلبية

    الفهرسة السلبية تعني البدء من النهاية، -1 تشير إلى العنصر الأخير، -2 تشير إلى العنصر الثاني والأخير.

    fruits = ['banana', 'orange', 'mango', 'lemon']
first_fruit = fruits[-4]
last_fruit = fruits[-1]
second_last = fruits[-2]
print(first_fruit)      # banana
print(last_fruit)       # lemon
print(second_last)      # mango

    lst = ['item1','item2','item3', 'item4', 'item5']

    تقطيع العناصر من القائمة

    • الفهرسة الإيجابية: يمكننا تحديد مجموعة من الفهارس الإيجابية من خلال تحديد البداية والنهاية والخطوة، وستكون القيمة المرجعة عبارة عن قائمة جديدة. (القيم الافتراضية للبداية = 0، النهاية = len(lst) - 1 (العنصر الأخير)، الخطوة = 1)
    fruits = ['banana', 'orange', 'mango', 'lemon']
all_fruits = fruits[0:4] # it returns all the fruits
# this will also give the same result as the one above
all_fruits = fruits[0:] # if we don't set where to stop it takes all the rest
orange_and_mango = fruits[1:3] # it does not include the first index
orange_mango_lemon = fruits[1:]
orange_and_lemon = fruits[::2] # here we used a 3rd argument, step. It will take every 2cnd item - ['banana', 'mango']
    • الفهرسة السالبة: يمكننا تحديد نطاق من الفهارس السالبة من خلال تحديد البداية والنهاية والخطوة، وستكون القيمة المرجعة عبارة عن قائمة جديدة.
    fruits = ['banana', 'orange', 'mango', 'lemon']
all_fruits = fruits[-4:] # it returns all the fruits
orange_and_mango = fruits[-3:-1] # it does not include the last index,['orange', 'mango']
orange_mango_lemon = fruits[-3:] # this will give starting from -3 to the end,['orange', 'mango', 'lemon']
reverse_fruits = fruits[::-1] # a negative step will take the list in reverse order,['lemon', 'mango', 'orange', 'banana']

    تعديل القوائم

    القائمة عبارة عن مجموعة مرتبة قابلة للتغيير أو التعديل من العناصر. يتيح تعديل قائمة الفاكهة.

    fruits = ['banana', 'orange', 'mango', 'lemon']
fruits[0] = 'avocado'
print(fruits)       #  ['avocado', 'orange', 'mango', 'lemon']
fruits[1] = 'apple'
print(fruits)       #  ['avocado', 'apple', 'mango', 'lemon']
last_index = len(fruits) - 1
fruits[last_index] = 'lime'
print(fruits)        #  ['avocado', 'apple', 'mango', 'lime']

    التحقق من العناصر في القائمة

    التحقق من عنصر ما إذا كان عضوًا في القائمة باستخدامفيمشغل. انظر المثال أدناه.

    fruits = ['banana', 'orange', 'mango', 'lemon']
does_exist = 'banana' in fruits
print(does_exist)  # True
does_exist = 'lime' in fruits
print(does_exist)  # False

    إضافة عناصر إلى القائمة

    لإضافة عنصر إلى نهاية القائمة الموجودة نستخدم الطريقةإلحاق ().

    # syntax
lst = list()
lst.append(item)

    fruits = ['banana', 'orange', 'mango', 'lemon']

    إدراج العناصر في القائمة

    يمكننا استخدامهاإدراج ()طريقة لإدراج عنصر واحد في فهرس محدد في القائمة. لاحظ أنه يتم نقل العناصر الأخرى إلى اليمين. الإدراج ()تأخذ الأساليب وسيطتين: الفهرس وعنصر لإدراجه.

    # syntax
lst = ['item1', 'item2']
lst.insert(index, item)

    fruits = ['banana', 'orange', 'mango', 'lemon']
fruits.insert(2, 'apple') # insert apple between orange and mango
print(fruits)           # ['banana', 'orange', 'apple', 'mango', 'lemon']
fruits.insert(3, 'lime')   # ['banana', 'orange', 'apple', 'lime', 'mango', 'lemon']
print(fruits)

    إزالة العناصر من القائمة

    تقوم طريقة الإزالة بإزالة عنصر محدد من القائمة

    # syntax
lst = ['item1', 'item2']
lst.remove(item)

    fruits = ['banana', 'orange', 'mango', 'lemon', 'banana']

    إزالة العناصر باستخدام Pop

    الالبوب ​​()الطريقة تزيل الفهرس المحدد (أو العنصر الأخير إذا لم يتم تحديد الفهرس):

    # syntax
lst = ['item1', 'item2']
lst.pop()       # last item
lst.pop(index)

    fruits = ['banana', 'orange', 'mango', 'lemon']
fruits.pop()
print(fruits)       # ['banana', 'orange', 'mango']

fruits.pop(0)
print(fruits)       # ['orange', 'mango']

    إزالة العناصر باستخدام Del

    الديلتقوم الكلمة الأساسية بإزالة الفهرس المحدد ويمكن استخدامها أيضًا لحذف العناصر الموجودة ضمن نطاق الفهرس. ويمكنه أيضًا حذف القائمة بالكامل

    # syntax
lst = ['item1', 'item2']
del lst[index] # only a single item
del lst        # to delete the list completely

    fruits = ['banana', 'orange', 'mango', 'lemon', 'kiwi', 'lime']
del fruits[0]
print(fruits)       # ['orange', 'mango', 'lemon', 'kiwi', 'lime']
del fruits[1]
print(fruits)       # ['orange', 'lemon', 'kiwi', 'lime']
del fruits[1:3]     # this deletes items between given indexes, so it does not delete the item with index 3!
print(fruits)       # ['orange', 'lime']
del fruits
print(fruits)       # This should give: NameError: name 'fruits' is not defined

    نسخ القائمة

    من الممكن نسخ قائمة عن طريق إعادة تعيينها لمتغير جديد بالطريقة التالية: list2 = list1. الآن، list2 هي مرجع للقائمة 1، وأي تغييرات نجريها في القائمة 2 ستؤدي أيضًا إلى تعديل القائمة 1 الأصلية. ولكن هناك الكثير من الحالات التي لا نرغب فيها في تعديل النسخة الأصلية بدلاً من ذلك نرغب في الحصول على نسخة مختلفة. إحدى طرق تجنب المشكلة المذكورة أعلاه هي الاستخدامينسخ().

    # syntax
lst = ['item1', 'item2']
lst_copy = lst.copy()

    fruits = ['banana', 'orange', 'mango', 'lemon']
fruits_copy = fruits.copy()
print(fruits_copy)       # ['banana', 'orange', 'mango', 'lemon']

    # syntax

    عكس القائمة

    اليعكس()الأسلوب يعكس ترتيب القائمة.

lst.reverse()

    fruits = ['banana', 'orange', 'mango', 'lemon']

    فرز عناصر القائمة

    لفرز القوائم يمكننا استخدامهانوع()طريقة أومرتبة ()وظائف مدمجة. النوع()تقوم الطريقة بإعادة ترتيب عناصر القائمة بترتيب تصاعدي وتعديل القائمة الأصلية. إذا كانت حجةنوع()الطريقة العكسية تساوي true، وسوف تقوم بترتيب القائمة بترتيب تنازلي.

    • النوع (): تقوم هذه الطريقة بتعديل القائمة الأصلية

      # syntax
lst = ['item1', 'item2']
lst.sort()                # ascending
lst.sort(reverse=True)    # descending

      مثال:

      fruits = ['banana', 'orange', 'mango', 'lemon']
fruits.sort()
print(fruits)             # sorted in alphabetical order, ['banana', 'lemon', 'mango', 'orange']
fruits.sort(reverse=True)
print(fruits) # ['orange', 'mango', 'lemon', 'banana']
ages = [22, 19, 24, 25, 26, 24, 25, 24]
ages.sort()
print(ages) #  [19, 22, 24, 24, 24, 25, 25, 26]

ages.sort(reverse=True)
print(ages) #  [26, 25, 25, 24, 24, 24, 22, 19]

      فرز (): إرجاع القائمة المرتبة دون تعديل القائمة الأصليةمثال:

      fruits = ['banana', 'orange', 'mango', 'lemon']
print(sorted(fruits))   # ['banana', 'lemon', 'mango', 'orange']
# Reverse order
fruits = ['banana', 'orange', 'mango', 'lemon']
fruits = sorted(fruits,reverse=True)
print(fruits)     # ['orange', 'mango', 'lemon', 'banana']
