    القواميس

    القاموس عبارة عن مجموعة من أنواع البيانات المقترنة (المفتاح: القيمة) غير المرتبة والقابلة للتعديل (القابلة للتغيير).

    إنشاء قاموس

    لإنشاء قاموس نستخدم الأقواس المتعرجة، {} أوإملاء ()وظيفة مدمجة.

    # syntax
empty_dict = {}
# Dictionary with data values
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}

    مثال:

    person = {
    'first_name':'Asabeneh',
    'last_name':'Yetayeh',
    'age':250,
    'country':'Finland',
    'is_marred':True,
    'skills':['JavaScript', 'React', 'Node', 'MongoDB', 'Python'],
    'address':{
        'street':'Space street',
        'zipcode':'02210'
    }
    }

    يوضح القاموس أعلاه أن القيمة يمكن أن تكون أي أنواع بيانات: سلسلة أو منطقية أو قائمة أو صف أو مجموعة أو قاموس.

    طول القاموس

    يتحقق من عدد أزواج "المفتاح: القيمة" في القاموس.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
print(len(dct)) # 4

    مثال:

    person = {
    'first_name':'Asabeneh',
    'last_name':'Yetayeh',
    'age':250,
    'country':'Finland',
    'is_married':True,
    'skills':['JavaScript', 'React', 'Node', 'MongoDB', 'Python'],
    'address':{
        'street':'Space street',
        'zipcode':'02210'
    }
    }
print(len(person)) # 7

    الوصول إلى عناصر القاموس

    يمكننا الوصول إلى عناصر القاموس من خلال الإشارة إلى اسمها الرئيسي.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
print(dct['key1']) # value1
print(dct['key4']) # value4

    مثال:

    person = {
    'first_name':'Asabeneh',
    'last_name':'Yetayeh',
    'age':250,
    'country':'Finland',
    'is_marred':True,
    'skills':['JavaScript', 'React', 'Node', 'MongoDB', 'Python'],
    'address':{
        'street':'Space street',
        'zipcode':'02210'
    }
    }
print(person['first_name']) # Asabeneh
print(person['country'])    # Finland
print(person['skills'])     # ['JavaScript', 'React', 'Node', 'MongoDB', 'Python']
print(person['skills'][0])  # JavaScript
print(person['address']['street']) # Space street
print(person['city'])       # Error

    يؤدي الوصول إلى عنصر ما بواسطة اسم المفتاح إلى حدوث خطأ في حالة عدم وجود المفتاح. لتجنب هذا الخطأ علينا أولاً التحقق من وجود مفتاح أو يمكننا استخدام ملفيحصلطريقة. تقوم طريقة get بإرجاع لا شيء، وهو نوع بيانات كائن NonType، إذا كان المفتاح غير موجود.

    person = {
    'first_name':'Asabeneh',
    'last_name':'Yetayeh',
    'age':250,
    'country':'Finland',
    'is_marred':True,
    'skills':['JavaScript', 'React', 'Node', 'MongoDB', 'Python'],
    'address':{
        'street':'Space street',
        'zipcode':'02210'
    }
    }
print(person.get('first_name')) # Asabeneh
print(person.get('country'))    # Finland
print(person.get('skills')) #['JavaScript', 'React', 'Node', 'MongoDB', 'Python']
print(person.get('city'))   # None

    إضافة عناصر إلى القاموس

    يمكننا إضافة أزواج مفاتيح وقيم جديدة إلى القاموس

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
dct['key5'] = 'value5'

    تعديل العناصر في القاموس

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
dct['key1'] = 'value-one'

    التحقق من المفاتيح في القاموس

    نحن نستخدمفيعامل للتحقق من وجود مفتاح في القاموس

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
print('key2' in dct) # True
print('key5' in dct) # False

    إزالة أزواج المفاتيح والقيمة من القاموس

    • البوب ​​(مفتاح): يزيل العنصر باسم المفتاح المحدد:
    • بوبيتم (): يزيل العنصر الأخير
    • ديل: يزيل عنصرًا باسم مفتاح محدد
    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
dct.pop('key1') # removes key1 item
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
dct.popitem() # removes the last item
del dct['key2'] # removes key2 item

    مثال:

    person = {
    'first_name':'Asabeneh',
    'last_name':'Yetayeh',
    'age':250,
    'country':'Finland',
    'is_marred':True,
    'skills':['JavaScript', 'React', 'Node', 'MongoDB', 'Python'],
    'address':{
        'street':'Space street',
        'zipcode':'02210'
    }
    }
person.pop('first_name')        # Removes the firstname item
person.popitem()                # Removes the address item
del person['is_married']        # Removes the is_married item

    تغيير القاموس إلى قائمة العناصر

    الأغراض()يغير الأسلوب القاموس إلى قائمة الصفوف.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
print(dct.items()) # dict_items([('key1', 'value1'), ('key2', 'value2'), ('key3', 'value3'), ('key4', 'value4')])

    مسح القاموس

    إذا كنا لا نريد العناصر الموجودة في القاموس فيمكننا مسحها باستخدامواضح()طريقة

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
print(dct.clear()) # None

    حذف قاموس

    إذا لم نستخدم القاموس فيمكننا حذفه بالكامل

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
del dct

    انسخ قاموسًا

    يمكننا نسخ القاموس باستخدام ملفينسخ()طريقة. باستخدام نسخة يمكننا تجنب حدوث طفرة في القاموس الأصلي.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
dct_copy = dct.copy() # {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}

    الحصول على مفاتيح القاموس كقائمة

    المفاتيح ()الطريقة تعطينا جميع مفاتيح القاموس كقائمة.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
keys = dct.keys()
print(keys)     # dict_keys(['key1', 'key2', 'key3', 'key4'])

    الحصول على قيم القاموس كقائمة

    القيمالطريقة تعطينا جميع قيم القاموس كقائمة.

    # syntax
dct = {'key1':'value1', 'key2':'value2', 'key3':'value3', 'key4':'value4'}
values = dct.values()
print(values)     # dict_values(['value1', 'value2', 'value3', 'value4'])
