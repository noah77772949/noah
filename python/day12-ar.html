    وحدات

    ما هي الوحدة النمطية

    الوحدة عبارة عن ملف يحتوي على مجموعة من الرموز أو مجموعة من الوظائف التي يمكن تضمينها في التطبيق. يمكن أن تكون الوحدة عبارة عن ملف يحتوي على متغير واحد أو دالة أو قاعدة تعليمات برمجية كبيرة.

    إنشاء وحدة

    لإنشاء وحدة نكتب أكوادنا في برنامج نصي بيثون ونحفظها كملف .py. قم بإنشاء ملف باسم mymodule.py داخل مجلد المشروع الخاص بك. دعونا نكتب بعض التعليمات البرمجية في هذا الملف.

    # mymodule.py file
def generate_full_name(firstname, lastname):
    return firstname + ' ' + lastname

    قم بإنشاء ملف main.py في دليل المشروع الخاص بك وقم باستيراد ملف mymodule.py.

    استيراد وحدة

    لاستيراد الملف نستخدم ملفيستوردالكلمة الأساسية واسم الملف فقط.

    # main.py file
import mymodule
print(mymodule.generate_full_name('Asabeneh', 'Yetayeh')) # Asabeneh Yetayeh

    وظائف الاستيراد من الوحدة النمطية

    يمكن أن يكون لدينا العديد من الوظائف في الملف ويمكننا استيراد جميع الوظائف بشكل مختلف.

    # main.py file
from mymodule import generate_full_name, sum_two_nums, person, gravity
print(generate_full_name('Asabneh','Yetayeh'))
print(sum_two_nums(1,9))
mass = 100
weight = mass * gravity
print(weight)
print(person['firstname'])

    وظائف الاستيراد من الوحدة النمطية وإعادة التسمية

    أثناء الاستيراد يمكننا إعادة تسمية اسم الوحدة.

    # main.py file
from mymodule import generate_full_name as fullname, sum_two_nums as total, person as p, gravity as g
print(fullname('Asabneh','Yetayeh'))
print(total(1, 9))
mass = 100 
weight = mass * g
print(weight)
print(p)
print(p['firstname'])

    استيراد الوحدات المضمنة

    مثل لغات البرمجة الأخرى، يمكننا أيضًا استيراد الوحدات عن طريق استيراد الملف/الوظيفة باستخدام الكلمة الأساسيةيستورد. لنقم باستيراد الوحدة المشتركة التي سنستخدمها في معظم الأوقات. بعض الوحدات المدمجة الشائعة:الرياضيات,التاريخ والوقت,نظام التشغيل,sys,عشوائي,إحصائيات,مجموعات,json,يكرر

    وحدة نظام التشغيل

    باستخدام بايثوننظام التشغيلمن الممكن تنفيذ العديد من مهام نظام التشغيل تلقائيًا. توفر وحدة نظام التشغيل في Python وظائف لإنشاء دليل العمل الحالي وتغييره وإزالة الدليل (المجلد) وجلب محتوياته وتغيير الدليل الحالي وتحديده.

    # import the module
import os
# Creating a directory
os.mkdir('directory_name')
# Changing the current directory
os.chdir('path')
# Getting current working directory
os.getcwd()
# Removing directory
os.rmdir()

    وحدة النظام

    توفر وحدة sys الوظائف والمتغيرات المستخدمة لمعالجة أجزاء مختلفة من بيئة تشغيل Python. تقوم الدالة sys.argv بإرجاع قائمة بوسائط سطر الأوامر التي تم تمريرها إلى برنامج Python النصي. العنصر الموجود في الفهرس 0 في هذه القائمة هو دائمًا اسم البرنامج النصي، وفي الفهرس 1 هو الوسيط الذي تم تمريره من سطر الأوامر.

    مثال لملف script.py:

    import sys
#print(sys.argv[0], argv[1],sys.argv[2])  # this line would print out: filename argument1 argument2
print('Welcome {}. Enjoy  {} challenge!'.format(sys.argv[1], sys.argv[2]))

    الآن للتحقق من كيفية عمل هذا البرنامج النصي كتبت في سطر الأوامر:

    python script.py Asabeneh 30DaysOfPython

    النتيجة:

    Welcome Asabeneh. Enjoy  30DayOfPython challenge!

    بعض أوامر النظام المفيدة:

    # to exit sys
sys.exit()
# To know the largest integer variable it takes
sys.maxsize
# To know environment path
sys.path
# To know the version of python you are using
sys.version

    وحدة الإحصاء

    توفر وحدة الإحصائيات وظائف للإحصائيات الرياضية للبيانات الرقمية. الوظائف الإحصائية الشائعة التي تم تعريفها في هذه الوحدة:يقصد,متوسط,وضع,com.stdevإلخ.

    from statistics import * # importing all the statistics modules
ages = [20, 20, 4, 24, 25, 22, 26, 20, 23, 22, 26]
print(mean(ages))       # ~22.9
print(median(ages))     # 23
print(mode(ages))       # 20
print(stdev(ages))      # ~2.3

    وحدة الرياضيات

    وحدة تحتوي على العديد من العمليات الحسابية والثوابت.

    import math
print(math.pi)           # 3.141592653589793, pi constant
print(math.sqrt(2))      # 1.4142135623730951, square root
print(math.pow(2, 3))    # 8.0, exponential function
print(math.floor(9.81))  # 9, rounding to the lowest
print(math.ceil(9.81))   # 10, rounding to the highest
print(math.log10(100))   # 2, logarithm with 10 as base

    الآن قمنا باستيرادالرياضياتالوحدة التي تحتوي على الكثير من الوظائف التي يمكن أن تساعدنا في إجراء العمليات الحسابية الرياضية. للتحقق من الوظائف التي حصلت عليها الوحدة، يمكننا استخدامهامساعدة (الرياضيات)، أودير (الرياضيات). سيعرض هذا الوظائف المتاحة في الوحدة. إذا أردنا استيراد وظيفة محددة فقط من الوحدة، فإننا نستوردها على النحو التالي:

    from math import pi
print(pi)

    من الممكن أيضًا استيراد وظائف متعددة في وقت واحد

    
from math import pi, sqrt, pow, floor, ceil, log10
print(pi)                 # 3.141592653589793
print(sqrt(2))            # 1.4142135623730951
print(pow(2, 3))          # 8.0
print(floor(9.81))        # 9
print(ceil(9.81))         # 10
print(math.log10(100))    # 2

    ولكن إذا أردنا استيراد جميع الوظائف في وحدة الرياضيات فيمكننا استخدام * .

    from math import *
print(pi)                  # 3.141592653589793, pi constant
print(sqrt(2))             # 1.4142135623730951, square root
print(pow(2, 3))           # 8.0, exponential
print(floor(9.81))         # 9, rounding to the lowest
print(ceil(9.81))          # 10, rounding to the highest
print(math.log10(100))     # 2

    عندما نقوم بالاستيراد، يمكننا أيضًا إعادة تسمية اسم الوظيفة.

    from math import pi as  PI
print(PI) # 3.141592653589793

    وحدة السلسلة

    وحدة السلسلة هي وحدة مفيدة للعديد من الأغراض. يوضح المثال أدناه بعض استخدامات وحدة السلسلة.

    import string
print(string.ascii_letters) # abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ
print(string.digits)        # 0123456789
print(string.punctuation)   # !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~

    وحدة عشوائية

    الآن أنت على دراية باستيراد الوحدات. دعونا نقوم باستيراد آخر لنتعرف عليه جيدًا. دعونا نستوردعشوائيالوحدة التي تعطينا رقمًا عشوائيًا بين 0 و 0.9999...عشوائيتحتوي الوحدة على الكثير من الوظائف ولكن في هذا القسم سنستخدمها فقطعشوائيوrandint.

    from random import random, randint
print(random())   # it doesn't take any arguments; it returns a value between 0 and 0.9999
print(randint(5, 20)) # it returns a random integer number between [5, 20] inclusive
