    الشروط

    بشكل افتراضي، يتم تنفيذ العبارات في برنامج Python بالتسلسل من الأعلى إلى الأسفل. إذا كان منطق المعالجة يتطلب ذلك، فيمكن تغيير التدفق التسلسلي للتنفيذ بطريقتين:

    • التنفيذ الشرطي: سيتم تنفيذ كتلة مكونة من عبارة واحدة أو أكثر إذا كان تعبير معين صحيحًا
    • التنفيذ المتكرر: سيتم تنفيذ كتلة مكونة من عبارة واحدة أو أكثر بشكل متكرر طالما كان تعبير معين صحيحًا. في هذا القسم سوف نغطيلو,آخر,إليفالبيانات. المقارنة والعوامل المنطقية التي تعلمناها في الأقسام السابقة ستكون مفيدة هنا.

    إذا كان الشرط

    في بايثون ولغات البرمجة الأخرى الكلمة الرئيسيةلويتم استخدامه للتحقق مما إذا كان الشرط صحيحًا ولتنفيذ رمز الكتلة. تذكر المسافة البادئة بعد القولون.

    # syntax
if condition:
    this part of code runs for truthy conditions

    مثال: 1

    a = 3
if a > 0:
    print('A is a positive number')
# A is a positive number

    كما ترون في المثال أعلاه، 3 أكبر من 0. كان الشرط صحيحًا وتم تنفيذ رمز الكتلة. أما إذا كان الشرط خاطئا فلا نرى النتيجة. ولكي نرى نتيجة الشرط الكاذب، يجب أن يكون لدينا كتلة أخرى، والتي ستكونآخر.

    إذا كان آخر

    إذا كان الشرط صحيحًا، فسيتم تنفيذ الكتلة الأولى، وإذا لم يكن الأمر كذلك فسيتم تنفيذ الشرط الآخر.

    # syntax
if condition:
    this part of code runs for truthy conditions
else:
     this part of code runs for false conditions

    مثال:

    a = 3
if a < 0:
    print('A is a negative number')
else:
    print('A is a positive number')

    ثبت أن الشرط أعلاه غير صحيح، وبالتالي تم تنفيذ الكتلة الأخرى. ماذا لو كانت حالتنا أكثر من اثنين؟ يمكننا استخدامهاإليف.

    إذا أليف آخر

    في حياتنا اليومية، نتخذ القرارات بشكل يومي. نحن نتخذ القرارات ليس من خلال التحقق من شرط أو شرطين، بل من خلال شروط متعددة. وكما هو الحال في الحياة، فإن البرمجة مليئة بالشروط أيضًا. نحن نستخدمإليفعندما يكون لدينا شروط متعددة.

    # syntax
if condition:
    code
elif condition:
    code
else:
    code

    مثال:

    a = 0
if a > 0:
    print('A is a positive number')
elif a < 0:
    print('A is a negative number')
else:
    print('A is zero')

    يد قصيرة

    # syntax
code if condition else code

    مثال:

    a = 3
print('A is positive') if a > 0 else print('A is negative') # first condition met, 'A is positive' will be printed

    الشروط المتداخلة

    يمكن أن تكون متداخلة الشروط

    # syntax
if condition:
    code
    if condition:
    code

    مثال:

    a = 0
if a > 0:
    if a % 2 == 0:
        print('A is a positive and even integer')
    else:
        print('A is a positive number')
elif a == 0:
    print('A is zero')
else:
    print('A is a negative number')

    يمكننا تجنب كتابة الشرط المتداخل باستخدام العامل المنطقيو.

    إذا الشرط والمشغلين المنطقيين

    # syntax
if condition and condition:
    code

    مثال:

    a = 0
if a > 0 and a % 2 == 0:
        print('A is an even and positive integer')
elif a > 0 and a % 2 !=  0:
     print('A is a positive integer')
elif a == 0:
    print('A is zero')
else:
    print('A is negative')

    إذا و أو العوامل المنطقية

    # syntax
if condition or condition:
    code

    مثال:

    user = 'James'
access_level = 3
if user == 'admin' or access_level >= 4:
        print('Access granted!')
else:
    print('Access denied!')
