📖 ما هو القاموس؟

القائمة تعتمد على أرقام للوصول، لكن القاموس يعتمد على "أسماء" (مفاتيح). مثل دفتر هاتف: الاسم مفتاح، والرقم قيمة.

Python
person = {
    "name": "أحمد",
    "age": 25,
    "city": "دمشق"
}

print(person["name"])
print(person["age"])
📤 النتيجة
أحمد
25

✏️ تعديل وإضافة

Python
person = {"name": "أحمد", "age": 25}

person["age"] = 26
person["job"] = "مبرمج"

print(person)
📤 النتيجة
{'name': 'أحمد', 'age': 26, 'job': 'مبرمج'}

الحذف

Python
person = {"name": "أحمد", "age": 25, "city": "دمشق"}

del person["city"]
print(person)

removed = person.pop("age")
print(removed)
📤 النتيجة
{'name': 'أحمد', 'age': 25}
25

🔍 الوصول الآمن

لو حاولت الوصول لمفتاح غير موجود بـ [] ستحصل على خطأ. لكن get() أكثر أماناً:

Python
person = {"name": "أحمد", "age": 25}

print(person.get("name"))
print(person.get("job"))
print(person.get("job", "غير محدد"))
📤 النتيجة
أحمد
None
غير محدد

🔄 المرور على القاموس

Python
person = {"name": "أحمد", "age": 25, "city": "دمشق"}

for key in person:
    print(key)

print("---")

for key, value in person.items():
    print(f"{key}: {value}")
📤 النتيجة
name
age
city
---
name: أحمد
age: 25
city: دمشق

🧰 دوال مهمة

الدالةالوظيفة
keys()كل المفاتيح
values()كل القيم
items()أزواج (مفتاح، قيمة)
get(k)قيمة المفتاح بأمان
update()دمج قاموس آخر
Python
person = {"name": "أحمد", "age": 25}

print(list(person.keys()))
print(list(person.values()))
print(len(person))
📤 النتيجة
['name', 'age']
['أحمد', 25]
2

✏️ تمارين

تمرين 1سهل

أنشئ قاموس لكتاب فيه: العنوان، المؤلف، السنة. واطبع كل قيمة.

💡 تلميح

استخدم {"title": "...", ...}.

✅ الحل
book = {
    "title": "مقدمة في البرمجة",
    "author": "أحمد",
    "year": 2024
}
print(book["title"])
print(book["author"])
print(book["year"])
تمرين 2سهل

أضف مفتاح "price" إلى قاموس الكتاب، ثم اطبعه كاملاً.

💡 تلميح

استخدم book["price"] = 50.

✅ الحل
book = {"title": "مقدمة", "author": "أحمد"}
book["price"] = 50
print(book)
تمرين 3متوسط

أنشئ قاموس طالب فيه 3 مواد ودرجاتها. اطبع المعدل.

💡 تلميح

استخدم sum(grades.values()) / len(grades).

✅ الحل
student = {"رياضيات": 90, "علوم": 85, "عربي": 88}
avg = sum(student.values()) / len(student)
print(avg)
تمرين 4متقدم

اطبع قاموس الطالب بأسلوب أنيق: "المادة: الدرجة".

💡 تلميح

استخدم .items().

✅ الحل
student = {"رياضيات": 90, "علوم": 85, "عربي": 88}
for subject, grade in student.items():
    print(f"{subject}: {grade}")

📝 اختبار

1. كيف نكتب قاموساً؟

أ) [ ]
ب) { }
ج) ( )
د) < >

2. الفرق بين القاموس والقائمة؟

أ) لا فرق
ب) القاموس مفاتيح، القائمة أرقام
ج) القائمة أسرع
د) القاموس أصغر

3. كيف نصل لقيمة مفتاح بأمان؟

أ) d["key"]
ب) d.get("key")
ج) d.find("key")
د) d.value("key")

4. دالة الحصول على الأزواج؟

أ) pairs()
ب) items()
ج) pairs
د) values()

🎓 خلاصة

  • ✅ القاموس بـ {} وبصيغة {"key": value}
  • ✅ الوصول بـ d["key"] أو d.get("key")
  • ✅ الإضافة والتعديل بنفس الصيغة
  • ✅ الحذف بـ del أو pop
  • ✅ keys(), values(), items()
