🎨 لماذا توجد أنواع؟

الحاسوب يميّز بين "5" (نص) و 5 (رقم). كل واحد منهما له خصائص مختلفة:

النوع الاسم مثال الاستخدام
intعدد صحيح25, -3, 0العدّ، الأعمار، النقاط
floatعدد عشري3.14, -0.5الأسعار، الأوزان، النسب
strنص"أحمد", "123"الأسماء، الرسائل، العناوين
boolمنطقيTrue, Falseالشروط، الحالات
🎓
قاعدة ذهبية: كل قيمة في Python لها نوع. النوع يحدد ما يمكنك فعله بالقيمة.
مثلاً: النص له طول، الرقم لا. الرقم يمكن جمعه، النص يُدمج.

🔢 الأعداد الصحيحة (int)

أي عدد بدون فاصلة عشرية. يمكن أن يكون موجباً، سالباً، أو صفراً.

Python
age = 25
temperature = -5
count = 0
big_number = 1000000

print(type(age))
print(type(temperature))
📤 النتيجة
<class 'int'>
<class 'int'>

ميزة Python المذهلة: الأرقام الضخمة

في معظم اللغات، الحد الأقصى للعدد الصحيح محدود. في Python؟ لا حد!

Python
huge = 99999999999999999999999999999
print(huge * 2)
📤 النتيجة
199999999999999999999999999998

🔬 الأعداد العشرية (float)

أي عدد فيه فاصلة عشرية. لاحظ أن Python تستخدم النقطة وليس الفاصلة العربية.

Python
price = 19.99
weight = 75.5
pi = 3.14159
negative = -2.5

print(type(price))

الأخطاء المضحكة للـ Float

⚠️ مفاجأة
print(0.1 + 0.2)
😱 النتيجة
0.30000000000000004

ما هذا؟ لماذا النتيجة غريبة؟

⚠️
هذه مشكلة معروفة في جميع لغات البرمجة! ليست خاصة بـ Python.

السبب: الحاسوب يخزّن الأرقام في النظام الثنائي (0 و 1). بعض الأعداد العشرية لا يمكن تمثيلها بدقة في هذا النظام.

الحل: عند الحاجة لدقة عالية (مثل المال)، استخدم decimal module.

النظام العلمي

للأرقام الصغيرة أو الكبيرة جداً:

Python
tiny = 1.5e-10   # = 0.00000000015
big = 2.5e8      # = 250000000
print(tiny)
print(big)

في Python، لا فرق. اختر ما يسهّل عليك:

message2 = 'He said "Hello"'

✅ القيم المنطقية (bool)

فقط قيمتان: True و False. لاحظ: بحرف كبير في البداية.

Python
is_student = True
is_married = False

print(type(is_student))
print(5 > 3)
print(10 == 5)
print("أ" == "أ")
📤 النتيجة
<class 'bool'>
True
False
True

عمليات المقارنة

الرمز المعنى مثال النتيجة
==يساوي5 == 5True
!=لا يساوي5 != 3True
>أكبر5 > 3True
<أصغر5 < 3False
>=أكبر أو يساوي5 >= 5True
<=أصغر أو يساوي3 <= 5True
⚠️
لا تخلط بين = و ==!
= للتعيين: x = 5
== للمقارنة: x == 5

🔄 تحويل الأنواع

يمكن تحويل قيمة من نوع لآخر:

Python
# نص إلى رقم
num_str = "100"
num_int = int(num_str)
print(num_int + 50)

# رقم إلى نص
num = 42
num_str2 = str(num)
print("العدد هو " + num_str2)

# نص عشري إلى رقم
price_str = "19.99"
price = float(price_str)
print(price * 2)
📤 النتيجة
150
العدد هو 42
39.98

⚠️ تحويلات تفشل

❌ خطأ
int("مرحبا")
💥 رسالة الخطأ
ValueError: invalid literal for int() with base 10: 'مرحبا'

السبب: لا يمكن تحويل نص غير رقمي إلى عدد.

الحيلة: سؤال المستخدم

Python
age_str = "25"
age = int(age_str)
print("بعد 10 سنوات:", age + 10)

🎨 f-strings — الطريقة الحديثة لتنسيق النصوص

هذه ميزة حديثة في Python (منذ 3.6) تجعل الكود أنظف بكثير.

❌ الطريقة القديمة

Python
name = "أحمد"
age = 25
print("اسمي " + name + " وعمري " + str(age) + " سنة")

✅ الطريقة الحديثة (f-string)

Python
name = "أحمد"
age = 25
print(f"اسمي {name} وعمري {age} سنة")

كيف؟ أضف حرف f قبل النص، ثم ضع المتغيرات بين {}.

مزايا f-string

Python
price = 19.99
quantity = 3
total = price * quantity

print(f"السعر: {price}")
print(f"الكمية: {quantity}")
print(f"الإجمالي: {total}")

# يمكن استخدام أي تعبير
print(f"5 + 3 = {5 + 3}")
print(f"الاسم بأحرف كبيرة: {'ahmed'.upper()}")
📤 النتيجة
السعر: 19.99
الكمية: 3
الإجمالي: 59.97
5 + 3 = 8
الاسم بأحرف كبيرة: AHMED
💎
استخدم f-strings دائماً في Python الحديثة. أسرع، أوضح، وأسهل قراءةً.

🐛 أخطاء شائعة

خطأ 1: جمع نص مع رقم

❌ خطأ
age = 25
print("عمري: " + age)
💥 رسالة الخطأ
TypeError: can only concatenate str (not "int") to str

الحل: استخدم str(age) أو f-string.

خطأ 2: نسيان f في f-string

❌ خطأ
name = "أحمد"
print("اسمي {name}")
💥 النتيجة الخاطئة
اسمي {name}

الحل: أضف حرف f: f"اسمي {name}"

خطأ 3: استخدام الأقواس الخطأ

❌ خطأ
name = "أحمد"
print(f"اسمي (name)")

الحل: استخدم {} وليس ().

✏️ تمارين تطبيقية

تمرين 1 سهل

أنشئ متغيراً age = 30 واطبع نوعه.

💡 تلميح

استخدم type().

✅ الحل 
age = 30
print(type(age))
تمرين 2 سهل

حوّل النص "3.14" إلى رقم عشري واطبعه مضروباً في 2.

💡 تلميح

استخدم float().

✅ الحل 
x = float("3.14")
print(x * 2)
تمرين 3 متوسط

أنشئ 3 متغيرات (اسم، مدينة، عمر)، ثم اطبع جملة كاملة باستخدام f-string.

💡 تلميح

لا تنسَ حرف f قبل النص، وضع المتغيرات بين {}.

✅ الحل 
name = "أحمد"
city = "دمشق"
age = 25
print(f"أنا {name} من {city} وعمري {age} سنة")
تمرين 4 متوسط

أنشئ متغير price = 49.99 و quantity = 3. احسب الإجمالي واطبعه بـ f-string مع كلمة "دولار".

💡 تلميح

الإجمالي = price * quantity

✅ الحل 
price = 49.99
quantity = 3
total = price * quantity
print(f"الإجمالي: {total} دولار")
تمرين 5 متقدم

أنشئ نصاً فيه اسمك، واطبع طوله، وأول حرف منه.

💡 تلميح

الطول بـ len()، والحرف الأول بـ name[0].

✅ الحل 
name = "أحمد"
print(f"عدد الحروف: {len(name)}")
print(f"أول حرف: {name[0]}")
