🤔 لماذا الشروط؟

الحياة مليئة بالقرارات: "إذا كان الجو ممطراً سآخذ مظلة". البرمجة كذلك — نحتاج لاتخاذ قرارات بناءً على شروط.

🎓
الشرط تعبير يعطي True أو False. إذا صحيح → نفّذ كوداً، وإلا → آخر.

🔹 جملة if

Python
age = 20

if age >= 18:
    print("أنت بالغ")
📤 النتيجة
أنت بالغ

3 قواعد:

  • if تنتهي بنقطتين :
  • الكود المنفّذ مُزاح 4 مسافات
  • Python تعتمد الإزاحة للكتلة
⚠️
لا تخلط بين مسافات و Tab. اختر واحداً وثبّت عليه.

🔸 else

Python
age = 15

if age >= 18:
    print("أنت بالغ")
else:
    print("أنت قاصر")
📤 النتيجة
أنت قاصر

🔷 elif

Python
grade = 85

if grade >= 90:
    print("ممتاز")
elif grade >= 80:
    print("جيد جداً")
elif grade >= 70:
    print("جيد")
elif grade >= 60:
    print("مقبول")
else:
    print("راسب")
📤 النتيجة
جيد جداً
💡
Python تفحص الشروط بالترتيب. أول شرط يتحقق → نفّذ → توقف.

📝 اختبار

1. كيف تنتهي if في Python؟

أ) بفاصلة منقوطة
ب) بنقطتين
ج) بأقواس
د) بمسافة

2. ما كلمة الشرط البديل؟

أ) elif
ب) else if
ج) otherwise
د) other

3. نتيجة 5>3 and 2>4؟

أ) True
ب) False
ج) خطأ
د) 5

4. الإزاحة الصحيحة؟

أ) Tab فقط
ب) مسافات ثابتة
ج) أي عدد
د) مسافة واحدة
