🤔 لماذا نحتاج الشروط؟

تخيّل أنك تكتب برنامجاً لموقع تسجيل دخول. كيف يعرف البرنامج إن كان المستخدم يملك حساباً أم لا؟ كيف يتحقق من كلمة المرور؟ كيف يقبل بعض الطلبات ويرفض غيرها؟

كل هذه الأسئلة تُحل بـ الشروط. بدون الشروط، برنامجك ينفّذ نفس التعليمات دائماً — بلا قرارات، بلا تفاعل، بلا ذكاء.

🎓
الشرط هو تعبير برمجي نتيجته إما True (صحيح) أو False (خطأ). بناءً على النتيجة، ينفّذ البرنامج كوداً أو آخر.

🔹 جملة if — الأساس البسيط

الصيغة العامة:

Python
if الشرط:
    # الكود الذي ينفّذ إذا كان الشرط صحيحاً

مثال عملي:

Python
age = 20

if age >= 18:
    print("أنت بالغ")
📤 النتيجة
أنت بالغ

تشريح الكود:

  • if = الكلمة المفتاحية للشرط
  • age >= 18 = الشرط (هل العمر 18 أو أكثر؟)
  • : = نقطتان لإنهاء سطر الشرط (إجباري!)
  • السطر التالي مُزاح (Indented) = الكود المنفّذ
⚠️
3 أخطاء قاتلة في if:
1. نسيان النقطتين :
2. نسيان الإزاحة (المسافات في بداية السطر)
3. خلط المسافات مع Tab — اختر واحداً فقط

🎨 الإزاحة في Python — مفهوم فريد

على عكس كل اللغات الأخرى، Python لا تستخدم {} لتحديد الكتل. تستخدم الإزاحة (Indentation):

Python
# صحيح — 4 مسافات
if True:
    print("داخل الشرط")
    print("سطر آخر داخل الشرط")

print("خارج الشرط")
❌ خطأ
if True:
print("داخل الشرط")
💥 رسالة الخطأ
IndentationError: expected an indented block
💡
قاعدة عملية: استخدم 4 مسافات دائماً. معظم المحررات تحوّل Tab تلقائياً لـ 4 مسافات. في Termux، عند الكتابة يدوياً، تأكد من الاتساق.

🔸 else — البديل

ماذا لو كان الشرط خاطئاً؟ نستخدم else لتنفيذ كود بديل:

Python
age = 15

if age >= 18:
    print("أنت بالغ")
else:
    print("أنت قاصر")
📤 النتيجة
أنت قاصر

ملاحظة: else لا تحتاج شرطاً — تُنفَّذ دائماً إن فشل الشرط السابق.

مثال عملي: تحقق من كلمة المرور

Python
password = "12345"
input_password = "12345"

if input_password == password:
    print("✅ تم تسجيل الدخول")
else:
    print("❌ كلمة المرور خطأ")
📤 النتيجة
✅ تم تسجيل الدخول

🔷 elif — شروط متعددة

عندما يكون لديك عدة احتمالات، استخدم elif (اختصار else if):

Python
grade = 85

if grade >= 90:
    print("ممتاز")
elif grade >= 80:
    print("جيد جداً")
elif grade >= 70:
    print("جيد")
elif grade >= 60:
    print("مقبول")
else:
    print("راسب")
📤 النتيجة
جيد جداً
💡
ترتيب مهم: Python تفحص الشروط بالترتيب من الأعلى للأسفل. أول شرط يتحقق → ينفّذ → يتوقف. لهذا نضع الشروط الصارمة أولاً.

مثال خاطئ شائع

❌ ترتيب خاطئ
grade = 95

if grade >= 60:
    print("مقبول")     # هذا سيتحقق دائماً!
elif grade >= 90:
    print("ممتاز")     # لن يصل هنا أبداً
elif grade >= 80:
    print("جيد جداً")

النتيجة الخاطئة:

📤 النتيجة الخاطئة
مقبول

رغم أن الدرجة 95 يجب أن تكون "ممتاز"! السبب: grade >= 60 يتحقق أولاً.

🔗 العوامل المنطقية

تسمح لك بدمج عدة شروط في شرط واحد:

العامل المعنى مثال النتيجة
andو — الطرفان صحيحان5 > 3 and 2 > 1True
orأو — أحدهما صحيح5 > 3 or 2 > 5True
notليس — نفي القيمةnot (5 > 3)False

1. العامل and

Python
age = 25
has_id = True

if age >= 18 and has_id:
    print("يمكنك الدخول")
else:
    print("ممنوع الدخول")
📤 النتيجة
يمكنك الدخول

2. العامل or

Python
day = "الجمعة"

if day == "الجمعة" or day == "السبت":
    print("عطلة نهاية الأسبوع!")
else:
    print("يوم عمل")
📤 النتيجة
عطلة نهاية الأسبوع!

3. العامل not

Python
is_blocked = False

if not is_blocked:
    print("مرحباً بك")
else:
    print("حسابك محجوب")
📤 النتيجة
مرحباً بك

🪆 الشروط المتداخلة

يمكنك وضع شرط داخل شرط — هذا يسمى Nested Conditions:

Python
age = 25
has_ticket = True

if age >= 18:
    if has_ticket:
        print("مرحباً بك في الحفل 🎉")
    else:
        print("تحتاج تذكرة")
else:
    print("صغار السن غير مسموح")
📤 النتيجة
مرحباً بك في الحفل 🎉

بديل أنظف بـ and

Python — أنظف
if age >= 18 and has_ticket:
    print("مرحباً بك في الحفل 🎉")
else:
    print("لا يمكنك الدخول")
💡
قاعدة عملية: إذا أمكن، استخدم and/or بدل الشروط المتداخلة. الكود يصبح أقصر وأسهل قراءة.

🎯 العامل الثلاثي (Ternary)

طريقة مختصرة لكتابة if/else في سطر واحد:

الطريقة التقليدية (3 أسطر)

Python
age = 20

if age >= 18:
    status = "بالغ"
else:
    status = "قاصر"

print(status)

الطريقة الثلاثية (سطر واحد)

Python
age = 20
status = "بالغ" if age >= 18 else "قاصر"
print(status)
📤 النتيجة
بالغ

الصيغة:

Python
القيمة_إذا_صحيح if الشرط else القيمة_إذا_خطأ

أمثلة إضافية

Python
score = 85
result = "ناجح" if score >= 60 else "راسب"
print(result)

num = 7
type_num = "زوجي" if num % 2 == 0 else "فردي"
print(type_num)
📤 النتيجة
ناجح
فردي

🐛 أخطاء شائعة

خطأ 1: نسيان النقطتين

❌ خطأ
if age >= 18
    print("بالغ")
💥 رسالة الخطأ
SyntaxError: expected ':'

خطأ 2: نسيان الإزاحة

❌ خطأ
if age >= 18:
print("بالغ")
💥 رسالة الخطأ
IndentationError: expected an indented block

خطأ 3: استخدام = بدل ==

❌ خطأ
password = "secret"
if password = "secret":
    print("صحيح")
💥 رسالة الخطأ
SyntaxError: invalid syntax

الحل: استخدم == للمقارنة، = للتعيين.

خطأ 4: ترتيب خاطئ للشروط

❌ منطق خاطئ
score = 95

if score >= 60:
    print("ناجح")
elif score >= 90:
    print("ممتاز")

الطالب حصل على 95 لكن النتيجة "ناجح" وليس "ممتاز" — لأن الشرط الأول تحقق. الحل: ابدأ بالشروط الأصعب.

✏️ تمارين تطبيقية

تمرين 1 سهل

أنشئ متغير num = 15 واطبع "زوجي" أو "فردي".

💡 تلميح

استخدم num % 2 == 0 لفحص الزوجي.

✅ الحل 
num = 15
if num % 2 == 0:
    print("زوجي")
else:
    print("فردي")
تمرين 2 سهل

أنشئ a = 10 و b = 25 واطبع الأكبر منهما.

💡 تلميح

استخدم if/else.

✅ الحل 
a = 10
b = 25
if a > b:
    print(a)
else:
    print(b)
تمرين 3 متوسط

أنشئ score = 75 واطبع التقدير حسب الجدول: 90+ → A، 80+ → B، 70+ → C، 60+ → D، أقل → F.

💡 تلميح

استخدم if/elif/else بالترتيب الصحيح.

✅ الحل 
score = 75
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
تمرين 4 متوسط

استخدم Ternary لطباعة "شاب" إذا كان العمر أقل من 30، وإلا "كبير".

💡 تلميح

الصيغة: a if condition else b

✅ الحل 
age = 25
status = "شاب" if age < 30 else "كبير"
print(status)
تمرين 5 متقدم

اكتب كوداً يحدد إن كان year = 2024 سنة كبيسة (تقبل القسمة على 4 وليس على 100، أو تقبل القسمة على 400).

💡 تلميح

استخدم and و or.

✅ الحل 
year = 2024
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print("سنة كبيسة")
else:
    print("ليست كبيسة")
