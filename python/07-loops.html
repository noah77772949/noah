🤔 لماذا الحلقات؟

تخيّل أن مديرك طلب منك طباعة الأرقام من 1 إلى 100 على الشاشة. لو كنت لا تعرف الحلقات، ستكتب 100 سطر print:

❌ الطريقة البدائية
print(1)
print(2)
print(3)
# ... 97 سطراً آخر
print(100)

مع الحلقات، كل هذا يصبح 3 أسطر فقط:

✅ مع الحلقات
for i in range(1, 101):
    print(i)
🎓
الحلقة (Loop) طريقة لتنفيذ كود معيّن عدة مرات دون كتابته مرة تلو الأخرى. إذا احتجت تنفيذ شيء 1000 مرة، اكتبه مرة واحدة داخل حلقة.

🔁 حلقة for — الأكثر استخداماً

تُستخدم عندما تعرف عدد التكرارات مسبقاً. الصيغة:

Python
for المتغير in القائمة:
    # الكود المتكرر

المثال البسيط:

Python
for i in range(5):
    print(i)
📤 النتيجة
0
1
2
3
4

تشريح الكود:

  • for = الكلمة المفتاحية للحلقة
  • i = اسم المتغير (يمكن أي اسم)
  • in = الكلمة للتنقل داخل القائمة
  • range(5) = تُنتج الأرقام من 0 إلى 4
  • : = نقطتان (إجباري)
  • السطر التالي مُزاح مثل if

🎯 دالة range — قلب حلقة for

range() هي دالة تنتج سلسلة من الأرقام. لها 3 أشكال:

1. range(n) — من 0 إلى n-1

Python
for i in range(5):
    print(i)
📤 النتيجة
0
1
2
3
4

⚠️ مهم: range(5) تُنتج 5 أرقام لكن تبدأ من 0 وتنتهي عند 4 (وليس 5!).

2. range(start, end) — من start إلى end-1

Python
for i in range(1, 6):
    print(i)
📤 النتيجة
1
2
3
4
5

3. range(start, end, step) — مع خطوة

Python
# خطوة 2 — الأرقام الزوجية
for i in range(0, 10, 2):
    print(i)
📤 النتيجة
0
2
4
6
8

🔄 حلقة while — التكرار حتى شرط

تُستخدم عندما لا تعرف عدد التكرارات مسبقاً، وتكرّر ما دام الشرط صحيحاً.

Python
i = 1
while i <= 5:
    print(i)
    i += 1
📤 النتيجة
1
2
3
4
5

الفروق بين for و while

for while
متى نستخدمها؟ عند معرفة عدد التكرارات عند التكرار حتى تحقق شرط
العداد تلقائي (range) يدوي (أنت تزيده)
سهولة الخطأ آمنة خطر الحلقة اللانهائية
⚠️
احذر الحلقة اللانهائية! لو نسيت i += 1 في المثال أعلاه، سيبقى i يساوي 1 للأبد، والشرط i <= 5 سيبقى صحيحاً للأبد. البرنامج سيستمر بلا توقف.

مثال عملي: عدّاد تنازلي

Python
countdown = 5
while countdown > 0:
    print(countdown)
    countdown -= 1
print("🚀 انطلاق!")
📤 النتيجة
5
4
3
2
1
🚀 انطلاق!

مثال آخر: جمع الأرقام حتى الصفر

Python
total = 0
num = 1

while num <= 10:
    total += num
    num += 1

print(f"المجموع: {total}")
📤 النتيجة
المجموع: 55

⏸️ break — إيقاف الحلقة

يوقف الحلقة فوراً ويتجاهل باقي التكرارات:

Python
for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("انتهت الحلقة")
📤 النتيجة
1
2
3
4
انتهت الحلقة

لاحظ: عندما وصل i إلى 5، خرجنا فوراً. لم تُطبع 5 ولا 6-10.

استخدام عملي: البحث عن قيمة

Python
numbers = [3, 7, 1, 9, 4, 6]
target = 9

for n in numbers:
    if n == target:
        print(f"وجدنا {target}!")
        break
    print(f"نفحص {n}...")
📤 النتيجة
نفحص 3...
نفحص 7...
نفحص 1...
وجدنا 9!

⏭️ continue — تخطي التكرار

يتخطى بقية الكود في هذه التكرار ويستمر بالتي بعدها:

Python
for i in range(1, 8):
    if i == 3:
        continue
    print(i)
📤 النتيجة
1
2
4
5
6
7

لاحظ: طُبعت كل الأرقام ما عدا 3.

استخدام عملي: تجاهل القيم السالبة

Python
numbers = [5, -3, 8, -1, 10, -7]
total = 0

for n in numbers:
    if n < 0:
        continue
    total += n

print(f"مجموع الموجبة: {total}")
📤 النتيجة
مجموع الموجبة: 23

الفرق بين break و continue

الكلمة التأثير
break يُوقف الحلقة بالكامل
continue يتخطى هذه الدورة فقط، ويستمر بالباقي

💡 else مع الحلقات — ميزة فريدة

Python تقدّم ميزة غير موجودة في معظم اللغات: else مع الحلقات.

Python
# مثال: البحث عن رقم
numbers = [3, 7, 1, 9, 4]
target = 5
found = False

for n in numbers:
    if n == target:
        print("وجدناه!")
        found = True
        break
else:
    print("لم نجده في القائمة")
📤 النتيجة
لم نجده في القائمة

القاعدة: else تُنفَّذ فقط إذا اكتملت الحلقة بدون break.

🐛 أخطاء شائعة

خطأ 1: نسيان زيادة المتغير في while

❌ خطأ — حلقة لا نهائية
i = 1
while i <= 5:
    print(i)
    # نسيت i += 1

النتيجة: يطبع 1 للأبد ويُجمّد التطبيق. الحل: أضف i += 1.

خطأ 2: نسيان النقطتين

❌ خطأ
for i in range(5)
    print(i)
💥 رسالة الخطأ
SyntaxError: expected ':'

خطأ 3: نسيان الإزاحة

❌ خطأ
for i in range(5):
print(i)
💥 رسالة الخطأ
IndentationError: expected an indented block

خطأ 4: تعديل القائمة أثناء الحلقة

❌ منطق خاطئ
nums = [1, 2, 3, 4, 5]

for n in nums:
    if n % 2 == 0:
        nums.remove(n)  # خطير!

تعديل القائمة أثناء المرور عليها يُربك Python. الحل: أنشئ قائمة جديدة.

✅ الطريقة الصحيحة
nums = [1, 2, 3, 4, 5]
new_nums = []

for n in nums:
    if n % 2 != 0:
        new_nums.append(n)

print(new_nums)

📝 اختبار سريع

1. ما ناتج list(range(3))؟

أ) [1, 2, 3]
ب) [0, 1, 2]
ج) [0, 1, 2, 3]
د) [3]

2. ماذا يفعل break؟

أ) يتخطى الدورة
ب) يوقف الحلقة كاملة
ج) يعيد التشغيل
د) لا شيء

3. كيف نطبع 0, 2, 4, 6, 8؟

أ) range(5)
ب) range(0, 10, 2)
ج) range(2, 8)
د) range(0, 8, 2)

4. ما خطر نسيان زيادة المتغير في while؟

أ) خطأ في السطر
ب) حلقة لا نهائية
ج) لا شيء
د) يتوقف تلقائياً

🎓 خلاصة الدرس

  • ✅ for للتكرار بعدد معروف
  • ✅ range(start, end, step) — النهاية غير مشمولة
  • ✅ while للتكرار حتى تحقق شرط
  • ✅ break يُوقف الحلقة كاملة
  • ✅ continue يتخطى الدورة الحالية فقط
  • ✅ for...else تُنفَّذ فقط بدون break
  • ✅ احذر الحلقة اللانهائية في while
  • ✅ يمكن الحلقة على النصوص والقوائم
