    الصفوف

    الصف عبارة عن مجموعة من أنواع البيانات المختلفة التي تكون مرتبة وغير قابلة للتغيير (غير قابلة للتغيير). تتم كتابة الصفوف بين قوسين دائريين، (). بمجرد إنشاء الصف، لا يمكننا تغيير قيمه. لا يمكننا استخدام أساليب الإضافة والإدراج والإزالة في الصف لأنها غير قابلة للتعديل (قابلة للتغيير). على عكس القائمة، لدى Tuple طرق قليلة. الطرق المتعلقة بالصفوف:

    • tuple(): لإنشاء صف فارغ
    • العد (): لحساب عدد العنصر المحدد في الصف
    • الفهرس (): للعثور على فهرس عنصر محدد في صف
    • +عامل التشغيل: لضم صفين أو أكثر وإنشاء صف جديد

    إنشاء Tuple

    • صف فارغ: إنشاء صف فارغ

      # syntax
empty_tuple = ()
# or using the tuple constructor
empty_tuple = tuple()

    • Tuple مع القيم الأولية

      # syntax
tpl = ('item1', 'item2','item3')

      fruits = ('banana', 'orange', 'mango', 'lemon')

    طول الصفوف

    نحن نستخدملين ()طريقة الحصول على طول الصفوف.

    # syntax
tpl = ('item1', 'item2', 'item3')
len(tpl)

    الوصول إلى عناصر Tuple

    • الفهرسة الإيجابية على غرار نوع بيانات القائمة، نستخدم فهرسة إيجابية أو سلبية للوصول إلى عناصر المجموعة.

      # Syntax
tpl = ('item1', 'item2', 'item3')
first_item = tpl[0]
second_item = tpl[1]

      fruits = ('banana', 'orange', 'mango', 'lemon')
first_fruit = fruits[0]
second_fruit = fruits[1]
last_index =len(fruits) - 1
last_fruit = fruits[last_index]

    • الفهرسة السلبية الفهرسة السالبة تعني البدء من النهاية، -1 يشير إلى العنصر الأخير، -2 يشير إلى العنصر الثاني الأخير، والسالب لطول القائمة/الصف يشير إلى العنصر الأول.

      # Syntax
tpl = ('item1', 'item2', 'item3','item4')
first_item = tpl[-4]
second_item = tpl[-3]

      fruits = ('banana', 'orange', 'mango', 'lemon')
first_fruit = fruits[-4]
second_fruit = fruits[-3]
last_fruit = fruits[-1]

    تقطيع الصفوف

    يمكننا تقسيم صف فرعي عن طريق تحديد نطاق من الفهارس حيث نبدأ وأين ننتهي في الصف، وستكون القيمة المرجعة عبارة عن صف جديد يحتوي على العناصر المحددة.

    • مجموعة من المؤشرات الإيجابية

      # Syntax
tpl = ('item1', 'item2', 'item3','item4')
all_items = tpl[0:4]         # all items
all_items = tpl[0:]         # all items
middle_two_items = tpl[1:3]  # does not include item at index 3

      fruits = ('banana', 'orange', 'mango', 'lemon')
all_fruits = fruits[0:4]    # all items
all_fruits= fruits[0:]      # all items
orange_mango = fruits[1:3]  # doesn't include item at index 3
orange_to_the_rest = fruits[1:]

    • مجموعة من المؤشرات السلبية

      # Syntax
tpl = ('item1', 'item2', 'item3','item4')
all_items = tpl[-4:]         # all items
middle_two_items = tpl[-3:-1]  # does not include item at index 3 (-1)

      fruits = ('banana', 'orange', 'mango', 'lemon')
all_fruits = fruits[-4:]    # all items
orange_mango = fruits[-3:-1]  # doesn't include item at index 3
orange_to_the_rest = fruits[-3:]

    تغيير الصفوف إلى القوائم

    يمكننا تغيير الصفوف إلى قوائم والقوائم إلى صفوف. Tuple غير قابل للتغيير إذا أردنا تعديل Tuple فيجب علينا تغييره إلى قائمة.

    # Syntax
tpl = ('item1', 'item2', 'item3','item4')
lst = list(tpl)

    fruits = ('banana', 'orange', 'mango', 'lemon')
fruits = list(fruits)
fruits[0] = 'apple'
print(fruits)     # ['apple', 'orange', 'mango', 'lemon']
fruits = tuple(fruits)
print(fruits)     # ('apple', 'orange', 'mango', 'lemon')

    التحقق من عنصر في Tuple

    يمكننا التحقق مما إذا كان العنصر موجودًا أم لا في صف باستخدامفي، تقوم بإرجاع قيمة منطقية.

    # Syntax
tpl = ('item1', 'item2', 'item3','item4')
'item2' in tpl # True

    fruits = ('banana', 'orange', 'mango', 'lemon')
print('orange' in fruits) # True
print('apple' in fruits) # False
fruits[0] = 'apple' # TypeError: 'tuple' object does not support item assignment

    الانضمام إلى الصفوف

    يمكننا ضم صفين أو أكثر باستخدام عامل التشغيل +

    # syntax
tpl1 = ('item1', 'item2', 'item3')
tpl2 = ('item4', 'item5','item6')
tpl3 = tpl1 + tpl2

    fruits = ('banana', 'orange', 'mango', 'lemon')
vegetables = ('Tomato', 'Potato', 'Cabbage','Onion', 'Carrot')
fruits_and_vegetables = fruits + vegetables

    حذف الصفوف

    ليس من الممكن إزالة عنصر واحد في الصف ولكن من الممكن حذف الصف نفسه باستخدامديل.

    # syntax
tpl1 = ('item1', 'item2', 'item3')
del tpl1

    fruits = ('banana', 'orange', 'mango', 'lemon')
del fruits
