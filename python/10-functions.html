📝 اختبار

1. الكلمة لتعريف دالة؟

أ) function
ب) def
ج) fun
د) define

2. الفرق بين print و return؟

أ) لا فرق
ب) print يعرض، return يُرجع قيمة
ج) return أسرع
د) print أقوى

3. نتيجة def f(x): x + 1 ثم f(5)؟

أ) 6
ب) 5
ج) None
د) خطأ

4. الصيغة الصحيحة لـ lambda؟

أ) lambda x: x * 2
ب) lambda(x) { x * 2 }
ج) x => x * 2
د) lambda x -> x * 2

🎓 خلاصة

  • ✅ def لتعريف الدوال
  • ✅ الوسائط بين الأقواس
  • ✅ return تُرجع قيمة وتوقف التنفيذ
  • ✅ القيم الافتراضية: def f(x=5)
  • ✅ lambda لدوال صغيرة بسطر واحد
