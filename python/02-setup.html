🧩 مملكة البرمجة: من يفعل ماذا؟

قبل أن نبدأ التثبيت، يجب أن نفهم الأدوار. كثير من المبتدئين يخلطون بين هذه المصطلحات الثلاثة:

⚙️

المفسر (Interpreter)

البرنامج الذي يُنفّذ كودك فعلاً. هو python.exe أو python في الطرفية.

📝

المحرر (Editor)

برنامج تكتب فيه الكود كنص. مثل Notepad, VS Code, أو حتى مدير الملاحظات.

🚀

بيئة التطوير (IDE)

محرر + أدوات مساعدة + مفسر مدمج. مثل PyCharm أو Thonny.

💡
تشبيه بسيط: المحرر = ورق وقلم. المفسر = المعلم الذي يقرأ ما كتبت. IDE = مكتب متكامل فيه ورق ومعلم وكل الأدوات.

💾 تثبيت Python — ويندوز

إذا كنت على ويندوز، اتبع هذه الخطوات:

1. حمّل المثبّت الرسمي

اذهب إلى الموقع الرسمي: python.org/downloads

حمّل آخر إصدار (3.12 أو أحدث). اختر Windows Installer (64-bit).

2. الخطوة الأهم عند التثبيت

⚠️
في أول شاشة من المثبّت، ضع علامة صح أمام خيار:

☑ Add Python to PATH

إذا نسيت هذا الخيار، لن تستطيع تشغيل Python من الطرفية لاحقاً، وستحتاج إعادة التثبيت.

3. اضغط Install Now

انتظر بضع دقائق حتى ينتهي التثبيت. لا تحتاج لتغيير أي إعدادات أخرى.

4. تحقق من التثبيت

افتح Command Prompt (اضغط Win+R واكتب cmd ثم Enter)، ثم اكتب:

CMD
python --version

يجب أن يظهر شيء مثل:

📤 النتيجة
Python 3.12.1

إذا ظهر رقم الإصدار، فأنت جاهز! إذا ظهرت رسالة 'python' is not recognized، فراجع الخطوة 2.

🍎 تثبيت Python — ماك (macOS)

الخبر الجيد: ماك يأتي مع Python 2 مثبتة مسبقاً، لكنها قديمة جداً. نحتاج Python 3 الحديثة.

الطريقة 1: من الموقع الرسمي (الأسهل)

حمّل من python.org/downloads نسخة macOS Installer، وثبّتها كأي برنامج آخر.

الطريقة 2: عبر Homebrew (للمتقدمين)

Terminal
brew install python3

تحقق من التثبيت

افتح Terminal واكتب:

Terminal
python3 --version
📌
لاحظ أننا نستخدم python3 وليس python. على ماك ولينكس، الأمر python قد يشير للنسخة القديمة 2.7.

🐧 تثبيت Python — لينكس

معظم توزيعات لينكس تأتي مع Python 3 مثبتة مسبقاً. تحقق أولاً:

Terminal
python3 --version

إذا لم تكن مثبتة، استخدم مدير الحزم حسب توزيعتك:

التوزيعة الأمر
Ubuntu / Debian sudo apt install python3
Fedora / RHEL sudo dnf install python3
Arch Linux sudo pacman -S python

🎮 REPL — غرفة التجارب التفاعلية

REPL اختصار لـ Read-Eval-Print Loop (اقرأ-نفّذ-اطبع-كرّر). وهو بيئة تفاعلية تُدخل فيها أمراً فينفّذه Python فوراً.

كيف تفتح REPL؟

افتح الطرفية واكتب:

CMD / Terminal
python

أو على ماك ولينكس:

Terminal
python3

سترى شيئاً كهذا:

📤 النتيجة
Python 3.12.1 (main, Dec 7 2023)
Type "help", "copyright", "credits" or "license" for more information.
>>>

الرمز >>> هو دعوة Python لك بالكتابة. جرّب:

Python REPL
>>> 2 + 3
5
>>> 10 * 5
50
>>> "أهلاً" + " بك"
'أهلاً بك'
>>> print("مرحباً")
مرحباً
⚡
REPL مثالي لتجربة الأوامر بسرعة. لا يحتاج حفظ ملف، ولا تشغيل، ولا أي شيء. اكتب فينفّذ. لكنه لا يحفظ عملك — عند الخروج يضيع كل شيء.

كيف تخرج من REPL؟

اكتب أحد الأوامر:

  • exit()
  • quit()
  • أو اضغط Ctrl + D (لينكس/ماك) أو Ctrl + Z ثم Enter (ويندوز)

📄 من REPL إلى ملف حقيقي

REPL رائع للتجارب، لكن البرامج الحقيقية تُحفظ في ملفات. لننشئ أول ملف:

1. أنشئ مجلداً جديداً

على سطح المكتب، أنشئ مجلداً اسمه python-learn.

2. افتح محرر نصوص

استخدم أي محرر: Notepad, VS Code, Sublime Text, أو حتى محرر بسيط مدمج.

3. اكتب هذا الكود

Python first.py 
# أول برنامج حقيقي لي
print("=" * 30)
print("  مرحباً بك في عالم Python")
print("=" * 30)

name = "أحمد"
age = 25

print("اسمي:", name)
print("عمري:", age, "سنة")
print("عمري بعد 5 سنوات:", age + 5)

4. احفظ الملف باسم first.py

⚠️
تأكد من أن نوع الملف "All Files" وليس "Text Document". وإلا سيُحفظ الملف كـ first.py.txt ولن يعمل.

5. شغّل الملف

افتح الطرفية، انتقل إلى المجلد، ثم شغّل:

CMD / Terminal
cd Desktop/python-learn
python first.py

يجب أن تظهر:

📤 النتيجة
==============================
  مرحباً بك في عالم Python
==============================
اسمي: أحمد
عمري: 25 سنة
عمري بعد 5 سنوات: 30
🎓
مبروك! هذا أول برنامج حقيقي لك يُحفظ على القرص، ويُشغّل من الطرفية، وينتج مخرجات. هذه هي دورة حياة البرمجة الكاملة.

🔍 تفكيك البرنامج سطراً بسطر

لنفهم ما فعلناه بالضبط:

السطر 1: تعليق

Python
# أول برنامج حقيقي لي

سطر يبدأ بـ # — Python تتجاهله تماماً. للتوثيق فقط.

السطر 2: طباعة خط فاصل

Python
print("=" * 30)

هنا سر صغير: "=" * 30 يعني "كرّر علامة = ثلاثين مرة". النتيجة: خط من 30 علامة يساوي.

السطر 5-6: المتغيرات

Python
name = "أحمد"
age = 25

المتغير صندوق نحفظ فيه قيمة. name يحتوي على "أحمد"، وage يحتوي على 25. (سنتعمق في المتغيرات في الدرس القادم)

السطر 8: طباعة نص ومتغير

Python
print("اسمي:", name)

نطبع النص "اسمي:" ثم فاصلة ثم قيمة المتغير. Python تطبع مسافة تلقائياً بينهما.

السطر 10: عملية حسابية

Python
print("عمري بعد 5 سنوات:", age + 5)

نطبع النص، ثم نحسب قيمة age + 5 أولاً (فتصبح 30) ثم نطبعها.

🐛 أول خطأ حقيقي — وكيف تحلّه

سنتعمد الآن عمل خطأ. عدّل السطر الأخير ليصبح:

❌ خطأ مقصود
print("عمري بعد 5 سنوات:", age + "5")

شغّل الملف مرة أخرى. سيظهر:

💥 رسالة الخطأ
Traceback (most recent call last):
  File "first.py", line 10, in <module>
    print("عمري بعد 5 سنوات:", age + "5")
TypeError: unsupported operand type(s) for +: 'int' and 'str'

لنتفكيك رسالة الخطأ هذه، فهي مهمة جداً:

الجزء المعنى
Traceback مسار تتبّع الخطأ — من أين بدأ
File "first.py" اسم الملف الذي به الخطأ
line 10 رقم السطر بالضبط — مهم جداً!
TypeError نوع الخطأ: عدم توافق الأنواع
unsupported operand... السبب: لا يمكن جمع int (عدد) مع str (نص)
🧠
قاعدة ذهبية: اقرأ رسالة الخطأ من الأسفل للأعلى:
1. آخر سطر = نوع المشكلة
2. ما قبله = مكان المشكلة (السطر)
3. أعلاه = مسار التنفيذ (للمشاريع الكبيرة)

الحل

المشكلة: age رقم صحيح، و"5" نص (بسبب علامات الاقتباس). لا يمكن جمعهما.

الحل: احذف علامات الاقتباس:

✅ صحيح
print("عمري بعد 5 سنوات:", age + 5)

🎯 4 مبادئ لتجنّب الأخطاء

  1. احفظ الملف دائماً قبل التشغيل. Python تقرأ من الملف المحفوظ، وليس من الشاشة.
  2. انتبه للمسافات البادئة (Indentation). Python حساسة جداً للمسافة في بداية السطر — سنشرح هذا لاحقاً.
  3. تأكد من امتداد .py. ليس .txt ولا .docx.
  4. اقرأ الخطأ من الأسفل. لا تخف منه، هو صديقك.

✏️ تمارين تطبيقية

تمرين 1 سهل

اطبع اسمك في سطر، ثم عمرك في سطر آخر.

💡 تلميح

استخدم print() مرتين.

✅ الحل 
print("أحمد")
print(25)
تمرين 2 سهل

اطبع خط فاصل من 50 علامة = ثم كلمة "قسم جديد" ثم خط آخر.

💡 تلميح

استخدم "=" * 50.

✅ الحل 
print("=" * 50)
print("قسم جديد")
print("=" * 50)
تمرين 3 متوسط

أنشئ متغير x = 10، واطبع مربّعه (x×x) وثلاثة أضعافه (x×3).

💡 تلميح

استخدم العملية * للضرب.

✅ الحل 
x = 10
print("مربعه:", x * x)
print("ثلاثة أضعافه:", x * 3)
تمرين 4 متقدم

أنشئ 3 متغيرات: اسمك، مدينتك، عمرك. واطبع جملة كاملة تجمعهم بجملة واحدة منسقة.

💡 تلميح

استخدم عدة وسائط في print().

✅ الحل 
name = "أحمد"
city = "دمشق"
age = 25
print("أنا", name, "من", city, "وعمري", age, "سنة")

📝 اختبار سريع

1. ما الأمر الذي يعرض إصدار Python؟

أ) python -v
ب) python --version
ج) version python
د) python.info

2. ما هو REPL؟

أ) اسم محرر نصوص
ب) مكتبة Python
ج) بيئة تنفيذ تفاعلية سطر بسطر
د) نوع من المتغيرات

3. عند كتابة "=" * 30، ما النتيجة؟

أ) 30
ب) سلسلة من 30 علامة =
ج) خطأ
د) لا شيء

4. من أين تقرأ رسالة الخطأ أولاً؟

أ) من الأعلى
ب) من الوسط
ج) من الأسفل
د) لا تقرأها
