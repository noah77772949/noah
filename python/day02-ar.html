    وظائف مدمجة

    في بايثون لدينا الكثير من الوظائف المضمنة. الوظائف المضمنة متاحة عالميًا لاستخدامك، مما يعني أنه يمكنك الاستفادة من الوظائف المضمنة دون استيراد أو تكوين. فيما يلي بعض وظائف Python المضمنة الأكثر استخدامًا:مطبعة(),لين (),يكتب(),كثافة العمليات (),يطفو(),شارع (),مدخل(),قائمة(),إملاء (),دقيقة (),الأعلى(),مجموع(),مرتبة (),يفتح(),ملف(),يساعد()، ودير (). في الجدول التالي سترى قائمة شاملة لوظائف بايثون المضمنة المأخوذة منوثائق بايثون.

    دعونا نفتح غلاف Python ونبدأ في استخدام بعض الوظائف المدمجة الأكثر شيوعًا.

    دعونا نتدرب أكثر باستخدام وظائف مدمجة مختلفة

    كما ترون من المحطة أعلاه، حصلت بايثون على كلمات محجوزة. نحن لا نستخدم الكلمات المحجوزة للإعلان عن المتغيرات أو الوظائف. سنغطي المتغيرات في القسم التالي.

    أعتقد أنك الآن على دراية بالوظائف المضمنة. دعونا نقوم بممارسة أخرى للوظائف المضمنة وسننتقل إلى القسم التالي.

    المتغيرات

    تقوم المتغيرات بتخزين البيانات في ذاكرة الكمبيوتر. يوصى باستخدام المتغيرات التذكيرية في العديد من لغات البرمجة. المتغير ذاكري هو اسم متغير يمكن تذكره وربطه بسهولة. يشير المتغير إلى عنوان الذاكرة الذي يتم تخزين البيانات فيه. الرقم في البداية، والحرف الخاص، والواصلة غير مسموح بها عند تسمية متغير. يمكن أن يكون للمتغير اسم قصير (مثل x، y، z)، ولكن يوصى بشدة باستخدام اسم أكثر وصفًا (الاسم الأول، اسم العائلة، العمر، البلد).

    قواعد الأسماء المتغيرة في بايثون

    • يجب أن يبدأ اسم المتغير بحرف أو بشرطة سفلية
    • لا يمكن أن يبدأ اسم المتغير برقم
    • يمكن أن يحتوي اسم المتغير فقط على أحرف أبجدية رقمية وشرطات سفلية (A-z، 0-9، و _ )
    • أسماء المتغيرات حساسة لحالة الأحرف (الاسم الأول والاسم الأول والاسم الأول والاسم الأول) هي متغيرات مختلفة)

    سوف نستخدم أسلوب تسمية متغير Python القياسي الذي تم اعتماده من قبل العديد من مطوري Python. يستخدم مطورو Python اصطلاح تسمية متغير لحالة الثعبان (snake_case). نستخدم الشرطة السفلية بعد كل كلمة لمتغير يحتوي على أكثر من كلمة واحدة (على سبيل المثال: الاسم الأول، الاسم الأخير، سرعة دوران المحرك). المثال أدناه هو مثال للتسمية القياسية للمتغيرات، وتكون الشرطة السفلية مطلوبة عندما يكون اسم المتغير أكثر من كلمة واحدة.

    عندما نقوم بتعيين نوع بيانات معين لمتغير، فإن ذلك يسمى إعلان المتغير. على سبيل المثال، في المثال أدناه، تم تعيين اسمي الأول لمتغير first_name. علامة المساواة هي عامل التخصيص. التعيين يعني تخزين البيانات في المتغير. علامة المساواة في بايثون ليست مساواة كما في الرياضيات.

    مثال:

    # Variables in Python
first_name = 'Asabeneh'
last_name = 'Yetayeh'
country = 'Finland'
city = 'Helsinki'
age = 250
is_married = True
skills = ['HTML', 'CSS', 'JS', 'React', 'Python']
person_info = {
   'firstname':'Asabeneh',
   'lastname':'Yetayeh',
   'country':'Finland',
   'city':'Helsinki'
   }

    دعونا نستخدممطبعة()ولين ()وظائف مدمجة. تأخذ وظيفة الطباعة عددًا غير محدود من الوسائط. الوسيطة هي قيمة يمكننا تمريرها أو وضعها داخل قوس الدالة، انظر المثال أدناه.

    مثال:

    print('Hello, World!') # The text Hello, World! is an argument
print('Hello',',', 'World','!') # it can take multiple arguments, four arguments have been passed
print(len('Hello, World!')) # it takes only one argument

    دعونا نطبع ونجد أيضًا طول المتغيرات المعلنة في الأعلى:

    أنواع البيانات

    هناك عدة أنواع من البيانات في بايثون. لتحديد نوع البيانات نستخدميكتبوظيفة مدمجة. أود أن أطلب منك التركيز على فهم أنواع البيانات المختلفة بشكل جيد للغاية. عندما يتعلق الأمر بالبرمجة، فإن الأمر كله يتعلق بأنواع البيانات. لقد قدمت أنواع البيانات في البداية، ويأتي ذلك مرة أخرى، لأن كل موضوع مرتبط بأنواع البيانات. سنغطي أنواع البيانات بمزيد من التفصيل في الأقسام الخاصة بكل منها.

    التحقق من أنواع البيانات والصب

    • التحقق من أنواع البيانات: للتحقق من نوع بيانات بيانات/متغير معين، نستخدم الأمريكتب أمثلة:
    # Different python data types
# Let's declare variables with various data types

first_name = 'Asabeneh'     # str
last_name = 'Yetayeh'       # str
country = 'Finland'         # str
city= 'Helsinki'            # str
age = 250                   # int, it is not my real age, don't worry about it

# Printing out types
print(type('Asabeneh'))          # str
print(type(first_name))          # str
print(type(10))                  # int
print(type(3.14))                # float
print(type(1 + 1j))              # complex
print(type(True))                # bool
print(type([1, 2, 3, 4]))        # list
print(type({'name':'Asabeneh'})) # dict
print(type((1,2)))               # tuple
print(type(zip([1,2],[3,4])))    # zip

    • Casting: تحويل نوع بيانات إلى نوع بيانات آخر. نحن نستخدمكثافة العمليات (),يطفو(),شارع (),قائمة,تعيينعندما نقوم بإجراء عمليات حسابية، يجب أولاً تحويل أرقام السلسلة إلى int أو float وإلا فإنها سترجع خطأ. إذا قمنا بربط رقم بسلسلة، فيجب تحويل الرقم أولاً إلى سلسلة. سنتحدث عن التسلسل في قسم السلسلة.

      أمثلة:

    # int to float
num_int = 10
print('num_int',num_int)         # 10
num_float = float(num_int)
print('num_float:', num_float)   # 10.0

# float to int
gravity = 9.81
print(int(gravity))             # 9

# int to str
num_int = 10
print(num_int)                  # 10
num_str = str(num_int)
print(num_str)                  # '10'

# str to int or float
num_str = '10.6'
num_float = float(num_str)  # Convert the string to a float first
num_int = int(num_float)    # Then convert the float to an integer
print('num_int', int(num_str))      # 10
print('num_float', float(num_str))  # 10.6
num_int = int(num_float)
print('num_int', int(num_int))      # 10

# str to list
first_name = 'Asabeneh'
print(first_name)               # 'Asabeneh'
first_name_to_list = list(first_name)
print(first_name_to_list)            # ['A', 's', 'a', 'b', 'e', 'n', 'e', 'h']

    أنواع البيانات الرقمية في بايثون:

    1. الأعداد الصحيحة: الأعداد الصحيحة (السالبة والصفر والإيجابية). مثال: ... -3، -2، -1، 0، 1، 2، 3 ...

    2. أرقام الفاصلة العائمة (الأرقام العشرية) مثال: ... -3.5، -2.25، -1.0، 0.0، 1.1، 2.2، 3.5 ...

    3. الأعداد المركبة مثال: 1 + ي، 2 + 4ي، 1 - 1ي
