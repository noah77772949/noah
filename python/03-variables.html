📦 ما هو المتغير؟

تخيّل مكتبة كبيرة فيها رفوف كثيرة. كل رف له ملصق يوضح ما فيه: "كتب التاريخ"، "روايات"، "قصص أطفال"... عندما تحتاج كتاباً، لا تبحث في كل المكتبة — تنظر للملصق وتذهب مباشرة.

المتغير هو بالضبط هذا: ملصق على مكان في ذاكرة الحاسوب، يحمل اسماً وقيمة.

🎓
تعريف: المتغير هو اسم يشير إلى قيمة مخزّنة في ذاكرة الحاسوب. عندما تكتب اسم المتغير في الكود، Python تستبدله بالقيمة.
🧠 كيف يعمل المتغير؟
📝 name = "أحمد"
⬇️
🔍 Python تحجز مكاناً في الذاكرة
⬇️
🏷️ تُسمّي المكان "name"
⬇️
💾 تضع فيه القيمة "أحمد"

✍️ إنشاء متغير

الطريقة بسيطة جداً:

Python
اسم_المتغير = القيمة

أمثلة حقيقية:

Python
name = "أحمد"
age = 25
height = 1.75
is_student = True

وهكذا أنشأنا 4 متغيرات:

المتغير القيمة النوع
nameأحمدنص (str)
age25عدد صحيح (int)
height1.75عدد عشري (float)
is_studentTrueمنطقي (bool)
📌
لاحظ: في Python لا نُعلن نوع المتغير. هي تفهمه تلقائياً من القيمة. هذا يسمى Dynamic Typing.

🎨 قواعد تسمية المتغيرات

ليس كل اسم صالح. إليك القواعد:

✅ مسموح:

  • الحروف الإنجليزية: name, age
  • الأرقام (لكن ليس في البداية): user1, score2
  • الشرطة السفلية: first_name, my_var
  • الحروف العربية: الاسم, العمر (يعمل لكن غير شائع)

❌ ممنوع:

  • البدء برقم: 1name ❌
  • المسافات: my name ❌
  • الرموز الخاصة: name!, name@ ❌
  • الكلمات المحجوزة: print, if, for ❌

🎯 قواعد أسلوبية (نصائح احترافية):

📖

أسماء واضحة

user_age أفضل من ua

🔡

حروف صغيرة

my_var أفضل من MyVar

➖

شرطة سفلية

first_name أفضل من firstName

🚫

لا اختصارات مبهمة

total أفضل من t

⚠️
Python حسّاسة لحالة الأحرف!
name ≠ Name ≠ NAME
كل واحد منها متغير مختلف تماماً.

🔄 تغيير قيمة متغير

المتغير كاسمه — قابل للتغيير. يمكنك إعطاؤه قيمة جديدة في أي وقت:

Python
score = 10
print("النتيجة الأولية:", score)

score = 25
print("بعد التحديث:", score)

score = score + 5
print("بعد إضافة 5:", score)
📤 النتيجة
النتيجة الأولية: 10
بعد التحديث: 25
بعد إضافة 5: 30

السطر الأخير مثير للاهتمام

Python
score = score + 5

كيف يمكن أن يكون المتغير على جانبي المعادلة؟

الترتيب في Python:

  1. يُحسب الجانب الأيمن أولاً: score + 5 = 25 + 5 = 30
  2. ثم تُخزّن النتيجة في المتغير على اليسار: score = 30
💡
اختصار مفيد: يمكنك كتابة score += 5 بدلاً من score = score + 5. نفس النتيجة، أقل كتابة.

وأيضاً: -= للطرح، *= للضرب، /= للقسمة.

🎭 المتغير يشير للقيمة (مفهوم عميق)

في Python، المتغير لا يحتوي على القيمة — بل يشير إليها. الفرق يبدو بسيطاً لكنه مهم جداً:

Python
a = 10
b = a
a = 20

print("a =", a)
print("b =", b)
📤 النتيجة
a = 20
b = 10

لماذا b ظلّ 10؟

لأن السطر b = a لم ينسخ "متغير a"، بل نسخ القيمة الحالية لـ a (وهي 10). فb أصبح له قيمة مستقلة.

🔗 ما حدث بالتفصيل
1️⃣ a = 10 → a يشير للقيمة 10
2️⃣ b = a → b يشير لنفس القيمة (10)
3️⃣ a = 20 → a الآن يشير لقيمة جديدة (20)
✅ b لا يزال يشير للقيمة القديمة 10
🧠
هذه الفكرة ستعود لاحقاً عندما نتحدث عن القوائم (Lists). القوائم تتصرف بشكل مختلف قليلاً، وهذا سيصبح مهماً جداً.

✨ تعدد التعيين

Python تسمح بإعطاء قيم متعددة في سطر واحد:

Python
x = y = z = 100
print(x, y, z)
📤 النتيجة
100 100 100

أو قيم مختلفة لمتغيرات مختلفة:

Python
name, age, city = "أحمد", 25, "دمشق"
print(name)
print(age)
print(city)
📤 النتيجة
أحمد
25
دمشق

🔀 التبديل الذكي

في معظم اللغات، لتبديل قيمتَي متغيرين تحتاج متغيراً مؤقتاً:

Python — الطريقة التقليدية
a = 5
b = 10

temp = a
a = b
b = temp

print("a =", a)
print("b =", b)

لكن في Python، هناك طريقة سحرية:

Python — الطريقة الذكية
a = 5
b = 10

a, b = b, a

print("a =", a)
print("b =", b)
📤 النتيجة
a = 10
b = 5
⚡
هذا واحد من أجمل اختصارات Python. سطر واحد بدل ثلاثة. السبب: Python تحسب الطرف الأيمن بالكامل أولاً ثم تُوزّع على المتغيرات.

🧪 معرفة نوع المتغير

نسيت نوع متغير؟ استخدم دالة type():

Python
name = "أحمد"
age = 25
height = 1.75
is_student = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))
📤 النتيجة
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

هذه هي الأنواع الأربعة الأساسية:

النوع يعني مثال
strنص (String)"أحمد"
intعدد صحيح (Integer)25
floatعدد عشري1.75
boolمنطقي (True/False)True

🐛 أخطاء شائعة

خطأ 1: استخدام متغير قبل تعريفه

❌ خطأ
print(score)
score = 10
💥 رسالة الخطأ
NameError: name 'score' is not defined

السبب: Python تنفّذ من الأعلى للأسفل. عند print(score) لم يكن المتغير موجوداً بعد.

خطأ 2: خطأ إملائي في الاسم

❌ خطأ
first_name = "أحمد"
print(frist_name)
💥 رسالة الخطأ
NameError: name 'frist_name' is not defined

لاحظ: كتبنا frist بدل first. خطأ حرف واحد يوقف البرنامج.

خطأ 3: الاستخدام قبل التعريف

❌ خطأ
print("نتيجتك:", result)
result = 100

نفس المشكلة: الترتيب مهم.
